Part I - Core Canvas HTML Standards

Canvas strips most modern CSS and all JavaScript. Write HTML as if you have no stylesheet.

Core Rule: Every element that needs visual formatting must carry its own inline style="" attribute. There are no external stylesheets. Write as if you have no stylesheet at all.

All text must meet WCAG 2.1 AA: 4.5:1 for normal text, 3:1 for large text (18pt+ or 14pt bold).

Part II - Accessibility Requirements

UVU must comply with Section 508 and WCAG 2.1 Level AA. Every page, assignment, and quiz must meet these rules.

2.1 Images - Alt Text Required

Every <img> tag must have an alt attribute. Alt text must be under 120 characters (Canvas flags anything longer).

<!-- Informational image -->
<img src="waveform.png"
     alt="Sine wave showing one complete cycle at 440 Hz"
     style="max-width:100%; height:auto;">

<!-- Decorative image -->
<img src="divider.png" alt="" role="presentation">

2.2 Headings - Proper Hierarchy

Never use <h1> inside a Canvas Page body. Canvas provides H1 from the page title automatically. Your content starts at H2. Never skip levels (H2 to H4 without H3). H3 as the first heading on a page is a Severe Panorama error.

2.3 Links - Descriptive Text and Title Required

Never use "click here" or "read more." All links must carry a title attribute. Links that open new tabs must warn the user.

2.4 Tables - Data vs. Layout

Table TypeRequired Treatment
Data table (rubrics, specs, comparisons)Must have <caption> (plain text, no style), <thead> with <th scope="col">, and <tbody>.
Layout table (side-by-side columns)Must have role="presentation". No caption, no th tags.
Decorative list (items stacked vertically)Use <div> elements. Avoids all table accessibility issues.

Caption Note: Canvas strips visually-hidden caption CSS. Use a plain <caption> tag with NO style attribute. <caption> and <th scope="col"> are always required together - missing either one is a separate flagged error. A two-column comparison table with labeled headers is a data table, not a layout table.

Set the title attribute on every <item> to the question bank or category name. All questions in the same category share the exact same title string. Do not use the question text as the title. Example: title="Network Wiring Standards" on every question in that bank.

Part XIV - Rubric CSV Import Standards

Required Header Row (exact text, case-sensitive)

Rubric Name, Criteria Name, Criteria Description, Criteria Enable Range, Rating Name, Rating Description, Rating Points, Rating Name, Rating Description, Rating Points, Rating Name, Rating Description, Rating Points

Program Standard Rating Scale

LevelPointsDescription
Full Credit100% of criterion pointsAll criteria for this section are met as described.
Partial Credit50% (round to nearest whole number)Some criteria met but submission is incomplete or missing required evidence.
No Credit0 pointsNot submitted or does not meet minimum requirements for this section.

No commas in ANY field. Canvas parses rubric CSVs by splitting on commas. A comma inside any field causes silent column misalignment - one or more criteria receive 0 points with no error message. Replace comma-separated lists with "and" or "or" as conjunctions throughout every field in every row.

Required Generation Method

All rubric CSV files must be generated using Python's csv.writer module with QUOTE_ALL. Verify every data row produces exactly 13 columns. CSV filename convention: COURSE_A#_Rubric.csv (example: DAPR3345_A4_Rubric.csv).

Python Generation Template and Audit Script 
import csv

header = ["Rubric Name","Criteria Name","Criteria Description","Criteria Enable Range",
    "Rating Name","Rating Description","Rating Points",
    "Rating Name","Rating Description","Rating Points",
    "Rating Name","Rating Description","Rating Points"]

with open('rubric.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f, quoting=csv.QUOTE_ALL)
    writer.writerows([header, criterion_row_1, criterion_row_2])

# Verify: every data row must show 13 columns
with open('rubric.csv', newline='') as f:
    for i, row in enumerate(csv.reader(f)):
        print(f'Row {i}: {len(row)} cols')

# Pre-import audit: scan for commas in Rating Description columns
with open('your_rubric.csv', newline='', encoding='utf-8') as f:
    for i, row in enumerate(csv.reader(f)):
        if i == 0: continue
        for col in [5, 8, 11]:
            if col < len(row) and ',' in row[col]:
                print(f'ISSUE: Row {i+1} col {col+1}: {row[col][:60]}')

Part XXII - Canvas Module and Page Naming (Option D)

The permanent naming system for all Canvas modules and pages across every DAPR course. Apply automatically when generating any Canvas content.

Module Title Pattern

Topic: M# - Descriptive Title (Week ##)

Sound: M2 - Sound and Hearing (Week 02) Sound: M3 - The Decibel (Week 03) Networking: M3 - Network Configuration (Week 08)

At rollover: update only the week parenthetical if pacing changed. Never rename pages.

Page Name Pattern

Topic: Descriptive Page Title (no module number, no week, no part number)

Sound: Overview Sound: The Decibel Sound: Sound Wave Properties Networking: Address Resolution Protocol EQ: EQ Lab

Why pages have no module number or week reference: If a page name included a module number or week, that page would need renaming every time its module was reordered or rescheduled. Across hundreds of pages and 12 courses over multiple semesters, that maintenance cost is unacceptable. The topic prefix alone sorts and groups pages correctly in every Canvas view.

Student File Naming Under Option D

The Canvas page name becomes Segment 2 of the student filename. Replace any colon with space-hyphen-space ( - ).
