Icon Reference Guide: What Each Icon Means

Every icon on assignment pages and course content follows a consistent system. This page explains what each icon signals and shows a complete example assignment so you know what to expect.

Action Icons

Action icons appear in section headers to signal what kind of step or activity follows. They orient you before you read the content.

Checklist

Use: A list of steps or items you must complete or verify - typically a pre-submit checklist or a list of required actions.

Example: "Before You Submit - verify your files are named correctly and your zip opens on another machine."

Deadline

Use: Marks a time-sensitive step or due date reminder within an assignment page.

Example: "This assignment closes at 11:59 PM on the due date. Late submissions are not accepted."

Download

Use: A file or resource the instructor is providing for you to download - starter sessions, stems, templates, or reference tracks. This is something coming to you, not something you turn in.

Example: "Download the provided Pro Tools session before starting this lab."

Email

Use: A step that requires sending an email - either to the instructor, a guest speaker, or a contact listed in the assignment.

Example: "Email your pitch to the studio coordinator by Friday."

External Link

Use: A link to an outside resource - a plugin manufacturer page, an Avid support article, or a reference document hosted outside Canvas. Links marked with this icon open in a new tab.

Example: "Avid Knowledge Base: Elastic Audio overview (opens in new tab)."

Peer Review

Use: A peer review step. Canvas assigns two classmates' work to you after the submission deadline passes. This icon marks where the peer feedback instructions appear.

Example: "Peer Feedback - listen to both assigned mixes and complete the rubric for each."

Callout Icons

Callout boxes appear throughout assignment pages to draw attention to specific categories of information. Each type has a distinct color border and icon so you can recognize it instantly.

Required

Green border and shield icon. Mandatory program standards and non-negotiable rules. If a Required callout says to do something a specific way, there is no alternative.

Example: "Submissions must follow the program file naming convention exactly."

Note

Blue border and info icon. Clarifications, reminders, and context that help you understand the assignment more fully. Notes prevent common points of confusion.

Example: "The WAV file inside your zip and the standalone WAV upload are the same file - export once and use it in both places."

Warning

Amber border and yield triangle. Common mistakes and gotchas that students encounter repeatedly. Read these even if you feel confident - they flag the things that cost points.

Example: "Saving a session copy without 'Copy All Audio Files' checked will produce a zip that plays back silent on the grader's machine."

Critical / Avoid

Red border and X icon. Hard rules and prohibited actions. Violating a Critical callout results in a zero or a resubmit with penalty, not a partial deduction.

Example: "Do not consolidate or flatten tracks before submitting. Grading requires the original edit structure."

Tip

Purple border and lightbulb icon. Optional shortcuts and workflow improvements the instructor recommends but does not require. Tips help you work faster or produce better results.

Example: "Use Alt+click on a send fader to reset it to unity rather than dragging."

FAQ

Pink border and question mark icon. Answers to questions students ask repeatedly. If something seems unclear, check FAQ callouts first before emailing the instructor.

Example: "Q: Can I use a different compressor plugin than the one shown? A: Yes - any compressor works as long as your settings are documented in the PDF."

Submission Icons

Submission icons appear in the "What to Submit" section at the bottom of every assignment page. Each icon identifies the file type you are uploading for that row. One row = one file or one upload action.

Session Zip

Use: A complete zipped Pro Tools session - the .ptx file, Audio Files folder, and Fade Files folder together in one zip archive. Use this icon specifically for PT session zips, not other zip types.

Filename pattern: Smith, John - EQ - EQ Lab.zip

ZIP Archive

Use: A zip archive that is NOT a Pro Tools session - for example, a bundle of stems, a folder of exported tracks, or a set of reference files. If it contains a .ptx, use the Session Zip icon above instead.

Filename pattern: Smith, John - Mixing - Stem Export.zip

Audio File

Use: A stereo mixdown/bounce (WAV) uploaded as a media recording. This is the same WAV file that is also inside your zip - export once and submit in both places. The assignment page specifies the required format; WAV is standard unless otherwise stated.

Filename pattern: Smith, John - EQ - EQ Lab.wav

Pro Tools Session File

Use: A standalone Pro Tools session file (.ptx only, no audio) when the assignment specifically calls for just the session file - usually when audio is already provided by the instructor and does not need to be re-submitted.

Filename pattern: Smith, John - MIDI - MIDI Lab.ptx

PDF Document

Use: A PDF documentation file. Export your Word doc as PDF before submitting - Canvas SpeedGrader previews PDF natively. Do not submit the .docx.

Filename pattern: Smith, John - EQ - EQ Lab.pdf

Generic Upload / What to Submit

Use: Serves two purposes. As a section header it marks the "What to Submit" area at the bottom of every assignment page. As a row icon it indicates a file upload that does not fit a more specific category - for example, a screenshot or a text file.

Example: Uploading a single screenshot as a standalone deliverable.

Video File

Use: A video file (.mp4) such as a screen recording, a walkthrough of your session, or a performance recording.

Filename pattern: Smith, John - Mixing - Mix Walkthrough.mp4

The Download icon is not a submission icon

The Download icon marks files the instructor is giving to you. It appears in the body of the assignment page, not in the "What to Submit" section. See the Action Icons section above.

Feedback Quality Icons

These icons appear in peer review lessons to illustrate the difference between unhelpful, helpful, and best-practice feedback. They are not used on submission pages.

Peer Feedback Quality Levels
Not Helpful Helpful Best
Vague, emotional, or unactionable. The person receiving it cannot do anything specific with this feedback. Specific enough to identify the problem. The person knows where to look, but not exactly what to change. Specific, constructive, and immediately actionable. Gives a location, a problem, and a concrete fix.
"The mix sounded weird to me." "The low end felt muddy throughout." "The kick at 2:14 is clipping the master bus - pull it down 2 dB and re-bounce."

WHAT AN ASSIGNMENT LOOKS LIKE IN PRACTICE

Example Assignment

The content below is a complete sample assignment page. It uses every icon and callout type described above so you can see them in context. This is not a real assignment - no submission is required.

Example Assignment: EQ - EQ Lab

Goals

  • Apply a parametric EQ to a vocal track and document your decisions.
  • Demonstrate frequency identification by ear and by analyzer.
  • Export a stereo mixdown/bounce that reflects your EQ choices.

Starter Session

Download the provided session before starting

Download EQ_Lab_Starter.zip from the Files section of this course. Unzip it into your sessions folder, then open the .ptx file in Pro Tools. Do not move or rename any of the folders inside the zip.

Note:
The starter session contains pre-routed tracks and a reference mix on the master fader. Do not move tracks or change routing - only add and adjust inserts on the vocal track.

Instructions

Complete each step in order
  1. Insert a parametric EQ plugin on the vocal track (DigiRack EQ III or Pro-Q 3).
  2. Use a high-pass filter to remove content below 100 Hz.
  3. Identify and cut the primary problem frequency by ear, then verify with a spectrum analyzer.
  4. Add a high shelf boost above 8 kHz to restore air (no more than +3 dB).
  5. Mixdown/bounce a stereo WAV at 44.1 kHz / 24-bit from the beginning of the session to the end of the last region.
  6. Fill in the PDF documentation template with screenshots of your EQ settings and your written rationale for each adjustment.
Do not use automatic EQ matching tools.
This lab requires manual frequency decisions. Using iZotope Match EQ, Ozone, or any AI-matching feature will result in a zero for the EQ criterion regardless of how the result sounds.
Tip:
Narrow your Q to around 3-4 when hunting for a problem frequency, then widen it slightly once you have found it. A wide cut on a harmless frequency does more damage than the problem you were solving.

Rubric (25 pts)

EQ Lab Rubric
Criterion Full Credit Partial Credit No Credit
1. High-Pass Filter - HPF applied at 100 Hz or below with a natural slope 5 pts - 0 pts
2. Problem Frequency Cut - Problematic frequency identified and reduced appropriately 10 pts 5 pts 0 pts
3. PDF Documentation - Screenshots and written rationale for each adjustment are complete 10 pts 5 pts 0 pts
Total 25 pts

Peer Feedback

After the deadline, review two classmates' mixdowns

Canvas assigns two submissions to you automatically after the due date passes. Listen to each mixdown/bounce and complete the peer review rubric. Focus on whether the EQ decisions are audible, whether the low end sounds clean, and whether the vocal sits clearly in the mix.

Your feedback must be specific enough for your classmate to act on it. Use the quality levels below as a guide.

Peer Feedback Quality Guide - EQ Lab
Not Helpful Helpful Best
"The vocal sounded off to me." "There is a harsh frequency in the upper mids that makes the vocal hard to listen to." "There is a 3-4 kHz harshness that builds up every time the vocalist hits an S or T - try a narrow 2-3 dB cut around 3.2 kHz and re-bounce."
"The low end was bad." "The high-pass filter does not seem to have been applied - there is rumble under the vocal." "The HPF sounds like it may be set below 60 Hz - the low-end rumble is still audible on headphones. Moving the cutoff up to around 100 Hz should clean that up without thinning the voice."
"Good job overall, I liked it." "The EQ decisions are clearly audible and the vocal sits better than the dry version." "The cut around 400 Hz is well-placed and clears the mud nicely. The air shelf adds presence without sounding hyped. The only adjustment I would consider is pulling back the shelf by about 1 dB - it starts to push past the natural tonality of the voice at louder moments."
FAQ:
Q: What if my assigned peer did not submit anything? Contact the instructor. Do not leave the review blank - submit a note saying no file was available and you will receive full credit for that review.

Before You Submit

File Naming Convention

All three files must share the same base name. Replace the colon in the assignment name with space-hyphen-space:

Smith, John - EQ - EQ Lab.zip
Smith, John - EQ - EQ Lab.wav
Smith, John - EQ - EQ Lab.pdf

Test your zip before uploading
Unzip your archive into a new folder on your desktop and confirm the .ptx opens and plays back correctly before submitting. A corrupted or incomplete zip cannot be graded and earns a zero.
Pre-submit checklist
  • Session saved with File > Save Copy In, "Copy All Audio Files" checked
  • Zip opens on a different machine and .ptx plays back
  • Mixdown/bounce exported at 44.1 kHz / 24-bit, no clipping on the master fader
  • PDF exported from Word (not a .docx upload)
  • All three files use the correct naming convention
