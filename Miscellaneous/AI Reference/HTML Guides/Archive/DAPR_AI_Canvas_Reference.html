1. Canvas HTML Rules

Stop: Canvas strips external stylesheets, all JavaScript, CSS Grid, Flexbox, CSS variables, Google Fonts, position:absolute/fixed, box-shadow, and filter. Write every element with inline style="" attributes. No exceptions.

What Canvas strips (never use these)

Removed / BrokenResult
<link rel="...">Completely removed
<style>...</style>Removed in most contexts
display:gridLayout collapses
display:flexNot rendered in older Canvas builds
@font-face / Google FontsBlocked
<script>All JS removed for security
position:absolute/fixedStripped or broken
--var CSS variablesNot supported
box-shadow, filterUsually stripped
class= (custom)No effect without inline rule
rgba() color valuesUse hex codes only

What Canvas supports (safe to use)

Element / PropertyNotes
style="" inlineOnly reliable CSS method
<table>Multi-column layout; use percentage widths
<h2> - <h6>Never use H1 inside content - Canvas owns H1
<p>, <strong>, <em>Safe
<ul>, <ol>, <li>Safe
<a href="...">Must include title= attribute
<img>Must include alt= attribute
<div style="...">, <span style="...">Block and inline containers
<hr>, <br>Safe for dividers and line breaks
Inline SVGPaste raw SVG directly; add role="img" aria-hidden="true"
<figure>, <figcaption>Use for Wikimedia Commons image attribution
<iframe>Safe for YouTube and trusted embeds

Layout rules

  • Multi-column layout: use <table role="presentation"> with percentage widths.
  • Stacked vertical lists: use <div> elements - never a table.
  • Image side-by-side: use stacked divs, not a two-column table. Canvas flags presentation tables with data-looking content.
  • Never use a table for decorative banners or totals - use a styled <div>.
  • Do not use manual digit-period labels (1. 2. 3.) inside divs. Canvas flags these as implied lists. Use word-based labels (First, Second, Third) or use actual <ol> elements.

Fonts (system-safe only)

  • Body and headings: font-family: Arial, Helvetica, sans-serif;
  • Code samples: font-family: "Courier New", Courier, monospace;
  • Quotes / callouts (sparingly): font-family: Georgia, "Times New Roman", serif;

Output format rule

Required: Output only the HTML that goes inside the Canvas content editor body. Do not include <!DOCTYPE>, <html>, <head>, or <body> tags. Canvas only uses the content between body tags.

Required: Confirm the folder path and all filenames before writing a single img tag. Never guess a filename. A page built with assumed filenames will have silently broken images in Canvas with no error message.

Raw URL pattern: https://raw.githubusercontent.com/uvu-dapr/Canvas/main/FOLDER/FILENAME.jpg

Always use raw.githubusercontent.com, never github.com. Verify at least one URL in a browser before building the Canvas page. You should see only the image with nothing around it.

8. Rubric CSV Rules

Required: Generate a companion rubric CSV alongside every assignment HTML page. Use Python csv.writer with QUOTE_ALL - no manual CSV construction.

Exact header row (case-sensitive)

Rubric Name, Criteria Name, Criteria Description, Criteria Enable Range, Rating Name, Rating Description, Rating Points, Rating Name, Rating Description, Rating Points, Rating Name, Rating Description, Rating Points

Rules

  • Rubric Name must be identical on every row of the same rubric.
  • Rating points must be in descending order (highest to lowest, left to right). Canvas rejects ascending order.
  • Criteria Enable Range: use false unless point ranges are explicitly requested.
  • Three rating levels per criterion: Full Credit (100%), Partial Credit (50% rounded), No Credit (0).
  • No commas in any field. This is the single most important rule. Commas in any field cause silent column misalignment on import - some criteria silently receive 0 points. Replace all commas with "and" or "or".
  • CSV filename convention: COURSE_A#_Rubric.csv (example: DAPR3345_A4_Rubric.csv).
  • After import, verify every criterion shows a non-zero point value in the Canvas Criteria Builder.

Standard rating descriptions

LevelPointsDescription
Full Credit100% of criterionAll criteria for this section are met as described.
Partial Credit50% roundedSome criteria met but submission is incomplete or missing required evidence.
No Credit0Not submitted or does not meet minimum requirements for this section.

10. PDF Documentation Block Rules (Part XVI)

  • Every numbered item must include its point value in parentheses on the same line: 1. EQ (15 pts)
  • Point values in the copy-paste block must exactly match the rubric table.
  • The "Keep with next" instruction appears inside the copy-paste box before the first numbered item.
  • Every numbered item has a [ Screenshot here ] placeholder line below its description.
  • Filename naming convention appears at the top in monospace.

Required instruction line at top of every copy-paste block: After pasting this into Word, select each numbered item line and apply Format - Paragraph - Line and Page Breaks - Keep with next. 12. Voice and Writing Standards

"You may include screenshots if needed.""Include two screenshots that clearly show the completed routing configuration."

Writing rule - dashes

Stop: No em dashes and no double hyphens (--) in any visible Canvas HTML content. Use a hyphen with spaces ( - ) as a separator in running text. Double dashes are permitted only inside HTML comments, which Canvas strips before rendering.

14. Pre-Publish Checklists

HTML page checklist

  • All styles are inline - no style blocks, no external CSS
  • Only Arial, Georgia, or Courier New fonts used
  • First heading in content area is H2 (never H1)
  • Layout uses presentation tables or stacked divs
  • All img tags have alt text under 120 characters (or alt="" for decorative)
  • All link text is descriptive - no "click here"
  • All a tags have a title= attribute
  • Heading hierarchy is logical - no skipped levels
  • Data tables have plain caption, thead, th scope="col", and tbody
  • No table used for decorative banners or totals - div used instead
  • All text/background combinations pass WCAG 4.5:1
  • #CC4400 replaced with #993300 or darker
  • Gold backgrounds use #212121 dark text, not white
  • No JavaScript embedded
  • No em dashes or double hyphens in visible content
  • No digit-period labels (1. 2.) inside divs
  • Canvas Accessibility Checker shows 0 issues before publishing
