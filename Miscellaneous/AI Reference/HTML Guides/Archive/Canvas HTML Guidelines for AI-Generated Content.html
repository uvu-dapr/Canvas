Canvas HTML Guidelines for AI-Generated Content

This page outlines what HTML works inside Canvas and how AI should generate content that will render correctly without being stripped or modified.

1. What Canvas Allows

  • Basic HTML elements such as headings, paragraphs, lists, tables, and links
  • Inline styling using the style attribute
  • Simple structure without external dependencies

2. What Canvas Removes or Modifies

  • Script tags and JavaScript
  • Full HTML documents (html, head, body tags)
  • External CSS stylesheets
  • Complex layouts using advanced CSS
  • Unapproved iframes or embeds

3. Required Rules for AI-Generated HTML

  1. Only generate HTML fragments, not full documents
  2. Do not include html, head, or body tags
  3. Do not include JavaScript
  4. Use inline styles only when necessary
  5. Keep structure simple and readable
  6. Avoid using classes or IDs unless absolutely needed
  7. Do not rely on external CSS or frameworks

6. Key Concept for AI

Canvas behaves like a filtered HTML environment. Even valid HTML may be rewritten or removed. AI should generate only simple, safe, and minimal HTML to ensure consistent results.

7. Summary

The safest approach is to keep HTML simple, avoid advanced features, and assume Canvas will sanitize anything that is not explicitly allowed.
