Pro Tools Session Cleanup and Submission Prep

A working session accumulates far more material than belongs in a final submission. Multiple takes, render artifacts, unused imports, false starts, and temp files all inflate the folder size. This tutorial walks through the complete workflow: saving a protected copy of your session first, then cleaning that copy down to only what is needed, bouncing the mix, and zipping for Canvas submission.

Complete these steps in order. Do not skip steps.

Assignment requirements always take priority. Every setting shown in this tutorial -- sample rate, bit depth, file format, file naming -- is an example based on a standard stereo mix assignment. Your actual assignment page lists the required settings for that specific project. If the assignment says 48 kHz, use 48 kHz. If the assignment uses a different naming convention, use that convention exactly. When this tutorial conflicts with your assignment page, follow the assignment page. No exceptions.

The strategy: Save Session Copy In first to create your submission folder. Then open that copy and do all cleanup work inside it. Your original session stays untouched as a backup. Everything you delete in the copy is gone permanently. That is the point. Smaller files, faster upload, cleaner submission.

Step 1 - Understand What You Are Starting With

The image below shows what a working session looks like before cleanup. Each track contains multiple clips from different takes and edits. Some tracks have audio starting late, some have gaps, and the vocal track at the bottom has two separate clip regions. The Audio Files folder on disk contains every file ever recorded or imported, including many that are not on the timeline at all.

This is normal for a project in progress. The steps below remove the excess and leave only what the session needs to play back correctly.

When you open a working session folder on disk, it may also contain folders and files that do not belong in a submission:

Video Files - Only present if you are also submitting a video. Otherwise this folder should not be in your submission.
Session File Backups - Auto-saves created by Pro Tools. Not needed for submission.
Clip Groups - Not needed unless specifically requested.
WaveCache.wfm - A display cache Pro Tools regenerates automatically on open. Not needed.

Save Session Copy In produces a new folder containing only what is needed. You do not manually delete these folders.

Step 3 - Check Fades and Crossfades Before Anything Else

Before you do any cleanup, make sure every clip that needs a fade or crossfade has one. Once you compact, clip boundaries are permanently rewritten and your opportunity to fix fades cleanly is gone.

Listen through the entire session from start to finish on headphones or monitors at a comfortable level.
Every clip that starts abruptly needs a fade-in. Every clip that ends abruptly needs a fade-out. Any two clips that butt against each other on the same track need a crossfade.
A click or pop at a clip boundary means a fade is missing or broken. Fix it now.
The beginning and end of the entire mix need fades. The very first sound should fade in from silence and the very last sound should fade out to silence. No hard starts and no abrupt endings.

Required: Every clip boundary must be clean. Every mix must open and close with a fade. A submission that clicks, pops, or starts abruptly has not been finished. Do not proceed to cleanup until the session sounds correct from the first sample to the last.

Step 4 - Save Session Copy In First

This is the first action you take in Pro Tools. Save Session Copy In creates a brand-new folder containing a copy of your session file and every audio file currently referenced on the timeline. Your original session folder stays completely untouched. All cleanup work happens inside this copy.

Go to File > Save Session Copy In...

In the dialog, set the following:

Audio File Type: as specified by your assignment (BWF .WAV shown as an example)
Sample Rate: as specified by your assignment (44.1 kHz shown as an example)
Bit Depth: as specified by your assignment (16-bit shown as an example)
Interleaved: checked
Items to Copy: check Audio Files and Convert to Specified Format
Destination: a new folder on your desktop named exactly as your assignment specifies

Use the settings your assignment specifies. The dialog above shows 44.1 kHz and 16-bit as an example for a standard stereo mix assignment. Spatial audio assignments such as Dolby Atmos sessions require 48 kHz. Any assignment that specifies a different sample rate, bit depth, or file format overrides what is shown here. Read your assignment before filling in this dialog.

Step 5 - Close the Original and Open the Copied Session

Close your current session in Pro Tools. Navigate to the new folder on your desktop and open the .ptx file inside it. All remaining steps are performed inside this copy. Your original session is your backup and stays closed.

Step 6 - Select All Unused Clips and Delete Them from Disk

The Clip List holds references to every audio file ever imported or recorded in this session, including clips that are no longer placed on any track. Select all unused clips and permanently delete them from disk. You are working in the copy. There is no reason to keep these files.

Mac: Press Command + Shift + U to select all unused clips in the Clip List.
Windows: Press Ctrl + Shift + U

You can also reach this from the Clip List menu (the small triangle or three-line icon at the top right of the Clip List panel): choose "Select > Unused".

Once unused clips are selected, clear them. On a Mac with a number pad, press the Clear key. On a MacBook without a dedicated Clear key, open the Clip List menu and choose "Clear Selected". The standard Delete key on a laptop keyboard will not trigger this dialog from the Clip List. When the dialog appears, choose Delete.

Choose Delete, not Remove. Remove only takes the reference out of Pro Tools and leaves the audio file sitting on disk. Delete removes the file from disk permanently. You are working in the submission copy. Everything unused in this folder is waste. Delete it. This is how you get the smallest possible zip file.

Pro Tools may show a warning before deleting some files:

This warning appears when Pro Tools detects that a file may still be referenced in the Undo queue, a plugin, or the clipboard. Click Yes. You have already verified your session sounds correct. The Undo queue and clipboard have no effect on how the session plays back. This is the submission copy. Delete the file.

Step 7 - Compact Selected Clips

Even the clips on your timeline contain more audio than is actually playing. Every time you trim a clip, the audio before and after the trim point stays in the file on disk. Compact rewrites each audio file so it contains only the audio that is used, plus a small buffer on each side.

Mac: Press Command + Shift + A to select everything in the Clip List.
Windows: Press Ctrl + Shift + A

To open the Compact menu, left-click the disclosure arrow in the top right corner of the Clips bin. This is the small triangle icon that opens the Clip List menu. From there, choose "Compact..." The arrow shown in the image below is the exact spot to click.

The Compact Selected dialog opens. The default Padding value is 1000 ms. Change it to 500 ms. This keeps half a second of audio before and after each clip boundary, which is enough for any crossfade, while removing roughly half the excess audio compared to the default. Click Compact.

Note: After compacting, Pro Tools automatically saves the session. The audio files are permanently rewritten. The original full-length versions are gone from this folder. This is the intended outcome. You are in the submission copy.

Step 8 - Bounce the Mix

With the session cleaned up, bounce the final mix. Go to File > Bounce Mix... The settings below are examples for a standard stereo mix assignment. Your assignment specifies the required format, sample rate, bit depth, and output configuration. Use those values, not the ones shown here.

File Type: as specified by your assignment (WAV BWF shown as an example)
Format: as specified by your assignment (Interleaved shown as an example)
Bit Depth: as specified by your assignment (16-bit shown as an example)
Sample Rate: as specified by your assignment (44.1 kHz shown as an example)
Destination: Bounced Files folder inside your session folder, not your desktop or Downloads

Bounce settings come from your assignment. A standard stereo mix assignment may call for 44.1 kHz 16-bit WAV. A Dolby Atmos assignment will require 48 kHz and a different output path entirely. Always read the assignment before bouncing. The values shown in the image above are examples only.

Name your bounce file exactly as your assignment specifies. The example below follows the naming convention for one specific assignment. Your assignment will give you the correct format.

LastName, FirstName - Assignment Name - Song Name.wav

Step 9 - Verify the Final Folder Structure

Before zipping, open the session folder and confirm it contains only what belongs:

Bounced Files - contains your bounce file named exactly as your assignment requires
Audio Files - contains only the compacted stems, nothing extra
The .ptx session file at the root, named exactly as your assignment requires

No Session File Backups. No WaveCache.wfm. No Clip Groups. No Video Files folder unless you are also submitting a video file.

You have been working in this session throughout the cleanup steps, so you already know it plays correctly. Before zipping, confirm the folder contains only the three items shown above. If you see Session File Backups, WaveCache.wfm, Clip Groups, or any extra folders that are not part of your submission, Save Session Copy In did not run correctly. Re-run it from your original session and repeat the cleanup steps in the new copy.

Step 10 - Close Pro Tools, Compress the Folder, and Test the Zip

Close Pro Tools before you compress. Press Command + Shift + W to close the session, or quit Pro Tools entirely. Do not skip this step.

Why you see extra folders while Pro Tools is open: Pro Tools regenerates WaveCache.wfm, Session File Backups, and other working folders automatically while any session is running. You will see those folders appear inside your submission folder as long as the session is open. This is normal behavior and does not mean your cleanup failed. The folders are created by Pro Tools after Save Session Copy In already ran, so they will not be present in the zip as long as you close Pro Tools before compressing. If you compress while the session is still open, those folders end up inside the zip. Close first, then compress.

Right-click the session folder on your desktop and choose "Compress". macOS creates a .zip file in the same location with the same name as the folder.

Name your ZIP file exactly as your assignment specifies. The example below follows the naming convention for one specific assignment. Your assignment will give you the correct format.

LastName, FirstName - Assignment Name - Song Name.zip

Before you upload, test the zip. Copy the zip file to another Mac. Double-click it. macOS automatically extracts the folder. Open the extracted folder, open the .ptx file in Pro Tools, and confirm the session opens with all audio files present and plays back correctly from start to finish. If Session File Backups, WaveCache.wfm, or Clip Groups appear inside the extracted folder, the session was still open when you compressed. Delete the zip, close Pro Tools completely, re-compress, and test again.

Windows note: On Windows, double-clicking a zip file opens a preview of the contents inside File Explorer without actually extracting it. The files are not usable until extracted. To properly extract on Windows, right-click the zip file and choose "Extract All", then choose a destination folder. Open the extracted folder and verify the session opens correctly before submitting. Do not try to open the .ptx file from inside the zip preview window.

Once you have confirmed the extracted session opens and plays back correctly, that same zip file is ready to upload to Canvas.

Step 11 - Upload the Zip File to Canvas

1. Open Canvas in your browser and navigate to this assignment.
2. Click "Submit Assignment".
3. Click "Choose File", or drag the zip file directly into the upload area if Canvas shows a drop zone.
4. Navigate to your desktop, select the .zip file, and click "Open".
5. Wait for the upload to finish completely. Do not close the browser tab while it is uploading. Large files can take several minutes on campus Wi-Fi.
6. Click "Submit Assignment" to finalize. Uploading alone does not submit. You must click Submit after the upload completes.

Confirm your submission: After submitting, Canvas shows a confirmation with a timestamp. If you do not see that confirmation, the submission did not go through. Check the assignment page to verify your file appears under Submission Details before the deadline.

A session submitted with hundreds of unused audio files, no bounce, or missing file errors on open is not a complete submission. Do the cleanup. It takes less time than you think and it is a professional habit you will use for the rest of your career.

If this assignment also requires a PDF of your work, do not include the PDF inside the zip file. Upload the PDF as a separate file submission. A PDF buried inside a session zip is not accessible and will not be graded.
