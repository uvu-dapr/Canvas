Shape system: callouts use bordered rectangles, submissions use rounded squares, actions use circles, and feedback quality uses table cells. If every icon below renders, all 26 GitHub references are live. After pasting into a Canvas page, run the Canvas accessibility checker — it should report zero issues.

Callout boxes (6 types)

Each callout type carries a locked color identity. The icon stroke color always matches the left border color of its box.

Required: Submit the full session folder as a single zipped file that includes all audio assets. Sessions submitted without audio receive zero points for the session criterion.

Note: Pro Tools bounces should be 44.1 kHz, 16-bit, interleaved unless the assignment states otherwise. Atmos sessions require at least 48 kHz.

Warning: Pro Tools will not include audio files in the session folder by default. Use File - Save Copy In with Copy All Audio Files checked before zipping.

Avoid: Never rename an image file after its URL has been used on a Canvas page. Every page referencing that file will silently show a broken image with no error message.

Tip: Name your session before you open any plug-ins. Pro Tools writes the session name into plug-in preset paths, and renaming later can break preset recall.

FAQ: "Do I need to consolidate my audio before zipping?" - Only if you have clips referencing audio outside the session folder. Save Copy In handles consolidation automatically when Copy All Audio Files is checked.

Submission file types (8 icons)

Each submission uses a tinted rounded square — this shape visually means "file" and is distinct from action circles. Stack these under an assignment description to show exactly what the student submits.

Submit / Upload - Student uploads any file to Canvas. Cloud with up arrow.
Download - Instructor provides a file for students to retrieve. Cloud with down arrow.
Audio file - WAV, MP3, or AIFF bounce. Example: Smith, John - EQ Lab - Dont Think Twice.wav
PDF / Document - Documentation PDF, DOCX, or TXT. Example: Smith, John - EQ Lab - Dont Think Twice.pdf
Session folder - Zipped Pro Tools session folder. Archive box with sine wave inside.
Pro Tools session (.ptx) - The session file itself, not the folder. Purple document with PTX label.
ZIP archive - Generic zipped file when the contents are not a Pro Tools session.
Video file - MP4, MOV, or any exported video.

Action icons (5 types)

Each action uses a tinted circle — shape-coded for "do this" tasks. Appears inline next to the action the student takes.

Contact / Email - Questions about this assignment? Send a Canvas message with your session name in the subject line.
Deadline / Due: 9:00 AM Friday by default. Always follow the specific deadline posted in Canvas.
Before submitting: verify all three filenames match. Open the zip to confirm the .ptx and audio files are inside.
Reference track: listen on YouTube (opens in new tab).
Peer review: cohort partner assigned. Post your comments before the next class meeting.

Feedback quality table (6 icon files)

This table references all six feedback SVGs from GitHub. The three standard colored-stroke versions appear in the light-tinted body cells. The three contrast-adjusted variants (white stroke for dark headers, dark stroke for the gold header) appear in the colored header row.

Feedback quality levels - comparison of vague, adequate, and actionable peer review.
Not Helpful Helpful Best
Vague, emotional, or impossible to act on. "Sounded weird to me." Specific enough to identify an issue. "The low end felt muddy." Specific, constructive, actionable. "The kick at 2:14 is clipping the master. Pull it down 2 dB and re-bounce."
