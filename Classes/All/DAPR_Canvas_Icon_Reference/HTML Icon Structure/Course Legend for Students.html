1. Icons on Assignment Pages

Every assignment page in this program uses a consistent set of icons. There are two shapes: hexagons and circles. The shape tells you the category. The color tells you the specific type.

Shape rule: A hexagon always means a file - something you submit or that your instructor provides. A circle always means an action - something to do or be aware of, such as a deadline, checklist, or link.

File icons - hexagon shape

Upload to Canvas - green hexagon You are submitting this file through the Canvas assignment page. Appears next to every required deliverable.
Download from Canvas - brown hexagon Your instructor is providing this file for you. Click the link below the icon to download it.
Audio bounce - indigo hexagon A stereo mixdown exported from your session. Format is WAV 44.1 kHz / 24-bit interleaved unless the assignment specifies MP3. Name it exactly as shown in the assignment.
PDF documentation - olive hexagon A PDF exported from Word after inserting screenshots. Copy the numbered block from the assignment page into Word, add your screenshots below each item, then export as PDF. See Section 4 below.
Zipped Pro Tools session - teal hexagon, PT label Your entire Pro Tools session folder compressed into a single ZIP. Use File - Save Copy In with Copy All Audio Files checked before zipping. See Section 6 below.
ZIP archive - teal hexagon, ZIP label A zipped folder whose contents are not a Pro Tools session - for example stems, a project folder, or a set of exported files.
Pro Tools session file (.ptx) - purple hexagon The .ptx session file itself inside the ZIP. Confirms the session file is named correctly and sitting at the root of the zipped folder.
Video file - orange hexagon An exported video file, typically MP4 or MOV. Appears on assignments requiring a screen recording or rendered video.

Action icons - circle shape

Deadline - dark orange circle The due date and time for this assignment. Default is 9:00 AM on the day listed unless the assignment page states otherwise.
Pre-submission checklist - green circle Run through this list before you click Submit. Checks include matching filenames across ZIP, PTX, WAV, and PDF; audio files inside the ZIP; and correct WAV export settings.
Peer review - purple circle A cohort partner has been assigned to review your work, or you are reviewing theirs. Post your written feedback before the next class meeting. See the assignment page for the rubric criteria.
External link - blue circle, arrow This link leads outside Canvas - for example to a reference track, software download, or documentation. It opens in a new browser tab.
Contact your instructor - blue circle, envelope Questions about this assignment go here. Send a Canvas message with your session filename in the subject line so your instructor can find your submission quickly.

2. File Naming Rules

Stop: Files named incorrectly will be returned ungraded. There are no exceptions and no partial credit for incorrect naming.

Every file you submit in this program uses the same three-segment pattern, separated by space-hyphen-space ( - ). The three segments are always in the same order.

Pattern with song name (mix assignments):
LastName, FirstName - Assignment Name - Song Name.ext Pattern without song name (process labs):
LastName, FirstName - Assignment Name.ext

Segment 1 - Your name

Use LastName, FirstName with a literal comma. Use your preferred name exactly as it appears in Canvas. Do not abbreviate or reorder.

Smith, John

Segment 2 - Assignment name

Use the full Canvas assignment name with original capitalization and spaces. Keep the module prefix. If the Canvas name contains a colon, replace it with a space-hyphen-space.

Canvas Page NameWhat Goes in Segment 2
EQ: EQ LabEQ - EQ Lab
Sound: The DecibelSound - The Decibel
Mixing: DAW Mix 1Mixing - DAW Mix 1

Segment 3 - Song name (mix assignments only)

Use the song title with normal capitalization and spaces. Strip apostrophes and all other punctuation (commas, periods, exclamation marks). Omit this segment entirely for process-only labs with no song deliverable.

Song TitleWhat Goes in Segment 3
Don't Think Twice, It's All RightDont Think Twice Its All Right
Knockin' on Heaven's DoorKnockin on Heavens Door
Mr. Tambourine ManMr Tambourine Man
Six of OneSix of One

4. PDF Documentation Workflow

Many assignments require a PDF that documents your work with screenshots. Here is the exact workflow.

  1. Open the Canvas assignment page and find the gray copy-paste block near the bottom.
  2. Select all the text in that block and copy it.
  3. Open a new blank Word document and paste.
  4. Select each numbered item line and apply: Format - Paragraph - Line and Page Breaks - Keep with next. This keeps the label attached to the screenshot below it and prevents orphaned headings at the bottom of a page.
  5. Below each numbered item, insert the required screenshot directly into the document. Delete the placeholder line [ Screenshot here ] after inserting.
  6. Name the document using the standard naming convention before exporting.
  7. Export as PDF: File - Export - PDF. Do not print to PDF if you can avoid it - Export produces a cleaner file.
  8. Submit the PDF to Canvas along with your other deliverables.
Note: The PDF is worth more points than you might expect - on a 25-point lab it is worth 15 points, and on a 100-point major mix it is worth 40 points. It documents that you completed the full workflow, not just the final bounce. Missing screenshots cost you significant points.

5. WAV Export Specifications

All WAV bounces in this program use the same settings unless an assignment specifies otherwise.

SettingRequired Value
File formatWAV (.wav)
Sample rate44.1 kHz
Bit depth24-bit
FormatInterleaved stereo
DurationFull length of the mix - no extra silence at the start or end
Warning: Do not submit MP3 files when WAV is required. Do not submit 16-bit or 32-bit files when 24-bit is required. Wrong specs count as incorrect delivery and lose points on the submission criterion.

6. Zipping a Pro Tools Session

Always use Save Copy In before zipping. This ensures all audio files travel with the session and nothing is missing when your instructor opens it.

  1. In Pro Tools, go to File - Save Copy In.
  2. In the dialog, check Copy All Audio Files.
  3. Name the saved copy using the standard naming convention. This will be the name of the .ptx file inside the zip.
  4. Choose a location on your desktop or a dedicated submissions folder.
  5. Click OK. Pro Tools creates a complete, self-contained session folder.
  6. In Finder, right-click the session folder and select Compress. This creates the ZIP file.
  7. Rename the ZIP file to match the session folder name exactly. The .ptx file inside and the .zip outside must share the same base name.
  8. Submit the ZIP to Canvas.
Stop: Do not zip a session folder that has missing audio files. If Audio Files or Fade Files are missing from inside the ZIP, your session zip receives zero points and the submission will be returned. Save Copy In with Copy All Audio Files checked prevents this.

8. Pre-Submission Checklist

Run through this list every time before you click Submit. These are the most common reasons submissions are returned.

  • All file names follow the LastName, FirstName - Assignment Name - Song Name pattern
  • Colons in the Canvas assignment name are replaced with space-hyphen-space ( - )
  • Apostrophes and punctuation are stripped from the song name segment
  • The ZIP filename, the .ptx inside it, the WAV, and the PDF all share the same base filename
  • The ZIP was created from a Save Copy In folder - audio files are inside
  • The WAV is 44.1 kHz, 24-bit, interleaved stereo
  • The PDF has a screenshot below every numbered item in the copy-paste block
  • Keep with next is applied to every numbered item line in the Word doc before export
  • The PDF filename matches the ZIP and WAV base name
  • All files are submitted to the correct Canvas assignment page before the deadline

9. Late Submissions and Returns

Assignments submitted after the due date follow the late policy stated in the course syllabus. Check your syllabus - the policy is the same for all DAPR lab courses.

Files returned ungraded due to naming errors or missing content are returned with a note in SpeedGrader comments. Correct the issue and resubmit. A resubmission after the deadline is subject to the late penalty even if the original submission was on time.

Most common reasons submissions are returned: incorrect file naming pattern, missing audio files inside the ZIP, wrong WAV export settings, PDF submitted without screenshots, or ZIP and WAV filenames do not match. Run through Section 8 before every submission.
