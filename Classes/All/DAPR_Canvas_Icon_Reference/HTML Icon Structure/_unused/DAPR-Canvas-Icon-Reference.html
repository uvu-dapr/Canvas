DAPR Canvas Icon System

Audio Program  |  Utah Valley University  |  Standardized Icon and Callout Box Reference

This document defines the complete icon system for DAPR Canvas HTML pages. Every icon is implemented as inline SVG code pasted directly into the Canvas HTML editor. No image files or uploads are required. Each icon has a unique color identity. The filename, hex codes, and intended use are listed for every icon so that any AI tool reading this document can reproduce identical output.

Canvas strips display:flex entirely. The copy-paste templates on this page use <table role="presentation"> for the icon-plus-text layout. This is the only method that works in Canvas. Do not use div/flex versions -- they render correctly in Safari but the icon disappears completely in Canvas.
Implementation Note

Icons are inline SVG at viewBox 0 0 24 24, stroke-width 2.2, stroke-linecap round, stroke-linejoin round, fill none. In Canvas callout boxes, the icon is 22x22 inside a narrow table cell. Canvas preserves inline SVG reliably. The icon grid above uses flex/grid for the reference view only -- those styles are in a stylesheet and are fine for browser viewing. Only the copy-paste templates below matter for Canvas.

HTML Callout Box Templates -- Canvas Safe (table layout, no flex)

Copy any template below into the Canvas raw HTML editor. These use table layout, not flex. The live preview above each template shows exactly how it will look in Canvas.
