DAPR Canvas Icon Reference

Audio Program  |  Utah Valley University  |  Every assignment page in this program uses these icons. Learn the shape and color system once and you can scan any page instantly.

Shape system - two shapes, two meanings

Hexagon = file. A hexagon always means a file - something you submit or that your instructor provides for download. The color and label inside the hexagon tell you which kind of file.

Circle = action. A circle always means something you need to do or be aware of - a deadline, a checklist, a link, a peer review task, or a way to contact your instructor.

What each color means

Each color has one fixed meaning within its shape family. Three colors appear in both families - for those, the shape tells you which meaning applies.

Shared colors are marked - check the shape when you see green, purple, or blue.

Submission file type icons - hexagon shape

Hexagon = file. Appears next to every file you submit or that your instructor provides for download.

Upload to Canvas - green hexagon
You are submitting this file through the Canvas assignment page. Appears next to every required deliverable.
Download from Canvas - brown hexagon
Your instructor is providing this file for you to retrieve. Click the link below the icon to download it.
Audio bounce - indigo hexagon
A stereo mixdown exported from your session. WAV 44.1 kHz / 24-bit interleaved, or MP3 320 kbps when specified. Name it exactly as shown in the assignment.
PDF documentation - olive hexagon
A PDF exported from Word after inserting screenshots. Copy the numbered block from the assignment page into Word, add your screenshots below each item, then export as PDF.
Zipped Pro Tools session folder - teal hexagon, PT label
Your entire Pro Tools session folder compressed into a single ZIP. Use File - Save Copy In with Copy All Audio Files checked before zipping. The ZIP, the .ptx inside it, and your WAV must all share the same base filename.
ZIP archive - teal hexagon, ZIP label
A zipped folder whose contents are not a Pro Tools session - for example stems, a project folder, or a set of exported files. Same teal color as the session ZIP because both are compressed archives.
Pro Tools session file (.ptx) - purple hexagon
The .ptx session file itself inside the ZIP. Appears when an assignment asks you to confirm the session file is named correctly and sitting at the root of the zipped folder.
Video file - orange hexagon
An exported video file, typically MP4 or MOV. Appears on assignments that require a screen recording or rendered video deliverable.

Action icons - circle shape

Circle = action. Appears inline with instructions, deadlines, links, and checklists. The two blue circle icons are shown together so you can see what they share and how the artwork distinguishes them.

Contact your instructor - blue circle, envelope
Questions about this assignment go here. Send a Canvas message with your session filename in the subject line so your instructor can find your submission quickly.
External link - blue circle, arrow
This link leads outside Canvas - for example to a reference track, a software download, or documentation. It opens in a new browser tab.
Deadline - dark orange circle
The due date and time for this assignment. Default is 9:00 AM on the day listed unless the assignment page states otherwise. Late submissions follow the course late policy.
Pre-submission checklist - green circle
Run through this list before you click Submit. Common checks: filenames match across ZIP, PTX, WAV, and PDF; audio files are inside the ZIP; WAV is 44.1 kHz 24-bit interleaved.
Peer review - purple circle
A cohort partner has been assigned to review your work, or you are reviewing theirs. Post your written feedback before the next class meeting. See the assignment page for the rubric criteria.

Filename matching rule - applies to every hexagon icon: The ZIP, the .ptx inside it, the WAV bounce, and the PDF must all share the same base filename. If the names do not match, your submission cannot be identified in SpeedGrader and will be returned ungraded.
