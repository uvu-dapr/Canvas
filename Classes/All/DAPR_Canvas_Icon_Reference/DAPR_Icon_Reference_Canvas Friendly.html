Raw URL Pattern

SVG files can be referenced via raw GitHub URL when needed. The base pattern is:

https://raw.githubusercontent.com/uvu-dapr/Canvas/main/Classes/All/DAPR_Canvas_Icon_Reference/[Filename].svg

Example - Callout_Required.svg:

https://raw.githubusercontent.com/uvu-dapr/Canvas/main/Classes/All/DAPR_Canvas_Icon_Reference/Callout_Required.svg

Critical: Canvas pages must use inline SVG, not img tags pointing at the GitHub files. The SVG code below is what gets pasted into Canvas. The GitHub files exist as source references and for non-Canvas uses only.

Callout Box Icons - 5 Types

These five callout box types cover every scenario in DAPR course pages. Each type has a locked color identity. The stroke color on the icon always matches the left border color of its box. Do not mix colors between types.

1. Required - Green Shield with Checkmark

File: Callout_Required.svg  |  Border / Icon stroke: #1B5E20  |  Background: #E8F5E9

When to use: Mandatory program rules. Compliance requirements. Must-follow instructions. Use this when the information is non-negotiable and a student who misses it will fail or lose points.

Required: Submit the full session folder as a zipped file. Include all audio assets. Sessions submitted without audio files receive zero points for the session criterion.

4. Critical / Stop - Red X Circle

File: Callout_Critical.svg  |  Border / Icon stroke: #C62828  |  Background: #FBE9E7

When to use: Hard rules with zero tolerance. Enforcement policies. Absolute prohibitions. Actions that cannot be undone or that will cause automatic point loss with no appeal. If doing the wrong thing here breaks something permanently or results in a failing grade, use Critical.

Action Icons - 5 Types

Action icons appear in callout boxes or inline to signal what the student needs to do. They are used less frequently than callout or submission icons. The five action types cover the most common student-facing actions in DAPR pages.

Contact / Email

File: Action_Email.svg  |  Stroke: #0D47A1  |  Background: #E3F2FD  |  Use: Contact the instructor via Canvas message. Email envelope shape.

Questions about this assignment? Send a Canvas message and include your session name in the subject line.

Deadline / Due Date

File: Action_Deadline.svg  |  Stroke: #F57F17  |  Background: #FFF8E1  |  Use: Due date or time-sensitive notice. Clock face with pointer hand. Use when the deadline needs extra visual emphasis beyond the Canvas due date field.

Due: Sunday at 11:59 PM. Late submissions are not accepted after the Canvas deadline closes.

Checklist / Task

File: Action_Checklist.svg  |  Stroke: #1B5E20  |  Background: #E8F5E9  |  Use: Pre-submission checklists, task lists, and verification steps. Checkbox with checkmark. Use at the end of assignment pages to summarize what to verify before submitting.

Before submitting: Verify all three filenames match exactly. Open the zip to confirm the .ptx and audio files are inside.

External Link

File: Action_External_Link.svg  |  Stroke: #0D47A1  |  Background: #E3F2FD  |  Use: Link opens in a new tab or leads to an external site. Always pair with an aria-label warning "(opens in new tab)" on the anchor tag. Box with arrow pointing out.

Download the stems from the shared Google Drive folder (opens in new tab).

Peer / Class

File: Action_Peer.svg  |  Stroke: #4A148C  |  Background: #F3E5F5  |  Use: Peer review assignments, class activities, group work, or cohort context. Two-person silhouette. Use when the task involves collaboration or feedback from classmates.

Peer Review: You will be assigned two classmates to review. Listen to both submissions before writing your feedback.

Feedback Quality Icons - 3 Levels

These three symbols appear as header cells in the feedback quality comparison table on peer review pages. They are not used as standalone callout boxes. Unicode characters are used here instead of SVG img tags because SVG stroke colors cannot be overridden when loaded as img - the icon files use matched stroke colors that turn invisible against their own background color. The gold Helpful header uses dark text (#212121) and a dark symbol - do not use white text on gold.

Feedback Quality Levels - Colors and Contrast Rules
Not Helpful Helpful Best
Vague, emotional, or impossible to act on. "Sounded weird to me." Specific enough to identify an issue. "The low end felt muddy." Specific, constructive, immediately actionable. "The kick at 2:14 is clipping the master bus. Pull it down 2 dB and re-bounce."

Contrast rule for the Helpful (gold) column: White text on #F9A825 produces a 2.9:1 ratio - that fails WCAG AA. Always use dark #212121 text on gold backgrounds. The icon stroke must also switch to #212121 on gold. The other two columns (red and green) pass with white text and white icon strokes.

When to Use Which Callout - Quick Decision Guide

Callout Box Selection by Situation
Situation Use This Callout Do Not Use
Student must do this or lose points Required (green) Note, Tip
Good to know, no penalty if missed Note (blue) Required, Warning
Common mistake that causes point loss but is fixable before submission Warning (yellow) Required, Critical
Hard rule, no exceptions, automatic failure if violated Critical (red) Warning, Required
Optional improvement, not graded Tip (purple) Required, Warning

Required: Do not use more than one or two callout boxes per section of a page. If every paragraph is a Required callout, none of them read as required. Reserve the red Critical box for genuine hard stops - it loses impact if overused.
