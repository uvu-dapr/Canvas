Finder Smart Folders

A Smart Folder looks like an ordinary folder in the sidebar, but it holds nothing at all. It is a saved search that runs live every time you open it, which makes it one of the more genuinely useful Finder features almost nobody turns on.

What a Smart Folder Actually Is

A Smart Folder does not move, copy, or store a single file. It displays whatever currently matches a set of search criteria you define once, and that result list updates automatically every time you open it - a file that starts matching shows up without you doing anything, and a file that no longer matches disappears the same way. The files themselves never leave their real, original locations.

Building One

The process is the same every time:

  1. Open Finder.
  2. Choose File > New Smart Folder.
  3. Set the search scope to either This Mac or a specific location using the bar at the top of the window.
  4. Click the + button to add a search criterion.
  5. Combine as many criteria as needed - each additional + button adds another condition.
  6. Click Save, give it a name, and choose whether to add it to the sidebar.

An Audio-Production Example

A genuinely useful Smart Folder for this program: set the Kind criterion to Audio, add a second criterion for Date Modified within the last 7 days, and save it as "Recent Audio." The result is a folder that always shows whatever audio you have touched in the last week, across your entire Mac, without you ever having to remember where each file actually lives.

Why This Beats a Normal Folder

A normal folder only contains what you manually drag into it, and it goes stale the moment a matching file gets added somewhere else or an old one gets deleted - nothing updates until you go fix it by hand. A Smart Folder never goes stale, because it is not really holding files at all; it is re-running its search every time it opens. The same file can also appear inside several different Smart Folders at once - a WAV file could show up in both a "Recent Audio" Smart Folder and a "Files Over 100 MB" Smart Folder simultaneously - without ever being duplicated on disk.
