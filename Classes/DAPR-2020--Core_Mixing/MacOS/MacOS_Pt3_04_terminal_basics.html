Terminal Basics

Terminal is a text-based way to talk directly to macOS, typing commands instead of clicking icons. This unit only asks for a handful of commands, but understanding what those few actually do turns Terminal from an intimidating black box into a genuinely useful tool - and makes commands like launchctl, covered on the Login Items, Launch Agents, and Launch Daemons page, make real sense.

Where Terminal Lives

Terminal.app sits inside Applications > Utilities, alongside Console, Disk Utility, and Audio MIDI Setup - the folder Apple reserves for the built-in tools that manage the Mac itself rather than doing user-facing creative work. Opening it drops you at a prompt showing your username, your Mac's name, and a blinking cursor waiting for a command.

Five Commands Worth Knowing

pwd - print working directory - shows the full path of the folder you are currently in.
ls - list - shows every file and folder inside the current directory.
cd - change directory - moves you into a different folder, by typing cd followed by a path.
open . - opens the current Terminal location as a Finder window - a fast bridge back from the command line to the graphical interface.
whoami - prints the username of whoever is currently logged in.

pwd confirming the home folder, ls listing everything inside it, and cd Documents moving into a subfolder - the prompt itself updates to show the new location.

Four Symbols That Mean Something Specific

. - the current directory - the folder you are already in.
.. - the parent directory - one level up from where you are.
~ - your home folder, exactly the same shortcut covered on the File-System Structure and Paths page.
/ - root, the very start of every absolute path - also covered on that same page.

Tab Completion

Typing the first few letters of a file or folder name and pressing Tab completes the rest automatically, or shows every match if more than one name fits. This is not just a convenience - it also protects against a typo turning one command into an entirely different, unintended one.

Do not paste Terminal commands from the internet unless you understand what they do.
Be especially cautious with any command that includes sudo - it runs with full administrator power and can affect the entire system, not just your own account. A command copied blindly from a forum post can do real, permanent damage. If you do not understand every word of a command, do not run it.
