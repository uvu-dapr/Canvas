Terminal Basics

Terminal is a text-based way to talk directly to macOS, typing commands instead of clicking icons. A handful of commands turn it from an intimidating black box into a genuinely useful tool for an audio engineer - one that can tell you more about a WAV file in five seconds than digging through an app's Get Info window ever could.

Where Terminal Lives

Terminal.app sits inside Applications > Utilities, alongside Console, Disk Utility, and Audio MIDI Setup - the folder Apple reserves for the built-in tools that manage the Mac itself. Opening it drops you at a prompt showing your username, your Mac's name, and a blinking cursor waiting for a command.

Terminal Commands Worth Trying

Each of these does something real and immediately visible - copy any of them in, try it, and see what happens.

open . - opens the current Terminal location as a real Finder window - the fastest bridge back from the command line to the graphical interface, and proof that a period on its own means "right here."
afinfo - prints the technical details of an audio file - sample rate, channel count, duration, bit depth, and format. Type afinfo followed by a space, then drag a WAV or AIFF file from Finder into the Terminal window and press Return.
afplay - plays an audio file straight through the Mac's speakers, no app required. Type afplay followed by a space, drag in an audio file, and press Return.
system_profiler SPAudioDataType - lists every audio device macOS currently recognizes. If an interface is missing from a DAW, this checks whether macOS itself can even see it - a real troubleshooting step, not just a demo.
caffeinate - keeps the Mac from sleeping for as long as it runs - useful during a long file transfer or bounce. Press Control-C to stop it.
Start with afinfo.
This is the command that makes the whole page click. Drag one of your own session's WAV files into a Terminal window after typing afinfo, and macOS hands back its exact sample rate, channel count, and format - proof that the operating system itself understands audio, underneath whatever DAW happens to be running.

Drag Files Into Terminal

This is probably the single most useful trick on this page. Typing out a full file path by hand is slow and easy to get wrong - instead, start typing a command, add a space, and drag the file itself from Finder directly into the Terminal window. macOS inserts the complete, correct path automatically, spaces and all.

Type afinfo, add a space, then drag in a file named My Mix.wav. Terminal fills in something like afinfo /Users/yourname/Desktop/My\ Mix.wav on its own - notice the backslash before the space, which is just how Terminal marks a space that is part of a filename rather than a break between words. There is no need to type any of that by hand; dragging the file does it correctly every time.

Just Enough Navigation

ls - list - shows every file and folder inside the current directory.
cd - change directory - moves into a different folder, typed as cd followed by a path.
open . - opens the current folder in Finder - already covered above, and worth knowing as a navigation command too.

ls listing a folder's contents, and cd Documents moving into a subfolder - the prompt itself updates to show the new location.

Tab Completion

Start typing a file or folder name and press Tab. Terminal completes the name automatically when it can, or shows every match if more than one name fits. This saves typing and helps prevent path errors.

Do not paste Terminal commands from the internet unless you understand what they do.
Terminal commands can make system-level changes very quickly. Be especially cautious with anything containing sudo, which gives a command full administrator privileges. The commands on this page are safe to experiment with - but do not assume every command found online carries the same low risk.
