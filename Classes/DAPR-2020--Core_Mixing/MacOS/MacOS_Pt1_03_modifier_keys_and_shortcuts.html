Modifier Keys and Essential Shortcuts

Five keys change the meaning of everything else you press, and a small set of shortcuts built on them cover most of what a Mac user does in a normal day. Learning these once means never hunting through a menu for something a keystroke already does faster.

The Five Modifier Keys

Command (⌘) - the primary key behind almost every menu-command shortcut - copy, paste, save, and most of what follows on this page.
Option (⌥) - unlocks alternate actions - reveals hidden menu items, forces a copy instead of a move while dragging a file, and modifies several shortcuts below into a related but different command.
Control (⌃) - opens the contextual right-click menu on anything - a file, a piece of text, a Dock icon.
Shift (⇧) - extends a selection to a range, and combined with Command turns several shortcuts into a related variant - notably the screenshot shortcuts below.
Fn / Globe - toggles between a key's special hardware function and its standard behavior. It also triggers dictation when pressed twice.

Everyday Editing Shortcuts

Command-C / Command-V - copy and paste - the most-used shortcut pair on any computer.
Command-X - cut. Unlike copy, this removes the original the moment you cut it, before you have pasted anywhere - use it carefully.
Command-Z - undo the last action. Pro Tools uses the identical shortcut for undoing edits inside a session.
Command-A - select everything in the current window or field.
Command-F - open a find or search field inside the current app.
Command-S - save the current document or session.
Command-I - opens Get Info in Finder, or applies italics in a text field, depending on which app is active.

App and Window Management, Recapped

Command-Tab, Command-` (backtick), Command-H, Command-Option-H, Command-W, and Command-Q all live on the Mac Interface and Application Behavior page - Command-Option-H in particular is worth knowing before anything else in this unit, since it clears visual clutter in a busy mix session in a single keystroke.

Force Quit, Directly

Option-Command-Escape - opens the Force Quit Applications window immediately, skipping the Apple menu entirely. Full troubleshooting guidance for when to use this lives on the Force Quit and Troubleshooting page.

Finder and Capture Shortcuts

Shift-Command-G - opens Go to Folder, letting you type a path and jump straight there - covered in depth on the Finder Deep Dive page.
Shift-Command-. - toggles whether hidden files and folders are visible in Finder.
Shift-Command-3 / 4 / 5 - capture the whole screen, a selected area, or open the full screenshot and recording toolbar - covered in depth on the Spotlight, Quick Look, and Screenshots page.

Spotlight and Quick Look, Previewed

Command-Space opens Spotlight, a system-wide search box for finding an app or file by name instead of navigating to it manually. Pressing Space with a file selected in Finder opens Quick Look, a preview of that file's contents without launching its full app. Both get a full page of their own next, including a practical example using Audio MIDI Setup.

Tie every shortcut to a muscle you already use.
If a shortcut here has an equivalent inside Pro Tools - undo, save, find - practice the macOS version until it is automatic. The two will not fight each other; they apply in different contexts, and having both wired in removes a constant, tiny mental tax during a session.
