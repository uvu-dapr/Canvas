macOS Unit - Naming Layout and Fastest Path to Canvas

Every local file is now named MacOS_PtN_##_slug - Part number, then sequence within that Part, then a short descriptive slug. Sorting the folder alphabetically now puts every file in exact reading order, Part by Part. The MacOS_Pt0_ files sort first on purpose - they're the two things to handle before touching any page.

Fastest Path to Canvas

Step 1 - Push images to GitHub first

  1. Unzip MacOS_Pt0_assets_images_all.zip.
  2. Copy every file inside it into /Users/adamwolson/Library/CloudStorage/Dropbox/apps/GitHub/Canvas/Classes/DAPR-2020--Core_Mixing/MacOS/ - flat, no subfolders.
  3. Open GitHub Desktop, confirm the new files show as changes, write a commit message, commit, and push.
  4. Wait about a minute for the raw.githubusercontent.com CDN to catch up before checking a page.

Step 2 - Create the 5 Modules

Canvas > Modules > + Module. Create these five, in this order:

  1. P1: Getting Around macOS
  2. P2: Understanding Files and Finder
  3. P3: Applications and macOS
  4. P4: Hardware, Storage, and Troubleshooting
  5. P5: Mac Skills for Audio Engineers

Step 3 - Create each Page, module by module

Every item in the tables below is a Page except one: the Final Project, which is highlighted and built under Canvas > Assignments in Step 4.
  1. Canvas > Pages > + Page.
  2. Paste the exact Canvas Item Name from the table into the title field.
  3. In the Rich Content Editor toolbar, click the </> icon (HTML Editor) to switch to raw HTML mode.
  4. Open the matching local file (listed in reading order below - just work top to bottom) and paste its full contents into the HTML Editor box.
  5. Switch back to Rich Content view to confirm it rendered correctly, then Save & Publish.
  6. Drag the finished page into its Module.
Because the files now sort correctly, you can open the whole output folder, select all the MacOS_Pt1_ files, and work straight down the list without hunting for the next one.

Step 4 - Build the Final Project assignment

  1. Canvas > Assignments > + Assignment.
  2. Title: macOS: P6: Mac Navigation Deep Dive - Assignment
  3. Points Possible: 125
  4. Submission Type: Online, File Upload, PDF
  5. Switch the description field to the HTML Editor and paste in the full contents of MacOS_Pt6_01_final_project_mac_navigation_deep_dive.html.
  6. Click Rubric > Find a Rubric > the upload/import icon, and upload MacOS_Pt6_01_final_project_rubric.csv.
  7. Save & Publish, then place it in Module 5.

Step 5 - Import the Quiz

  1. Course Settings > Import Course Content.
  2. Content Type: QTI .zip file.
  3. Choose MacOS_Pt6_02_quiz_mac_navigation_qti.zip and click Import.
  4. Rename it to macOS: P6: Mac Navigation Deep Dive - Quiz if it did not already pick up that name, confirm it is graded, and accept conversion to a New Quiz if your course uses that.
  5. Publish it and add it to a Module.

Step 6 - Publish and double-check two renames

Two pages were revised in place from earlier versions with different titles. Canvas does not rename a live page automatically just because the pasted content changed - rename these two manually:

MacOS_Pt3_01_installing_software_dmg_app_pkg.html was previously titled "Installers: DMG vs. EXE" - set its Canvas title to macOS: P3: Installing Software - DMG, APP, and PKG

MacOS_Pt3_03_login_items_launch_agents_daemons.html was previously titled "Launch Agents vs. Launch Daemons" - set its Canvas title to macOS: P3: Login Items, Launch Agents, and Launch Daemons
