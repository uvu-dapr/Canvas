Applications and Utilities

Most Mac software installs itself with a single drag, and uninstalls with a single delete - but that simplicity hides a few files that get left behind every time. Knowing where those files go, and why, explains a whole category of utility apps built specifically to clean them up.

Why Most Mac Apps Don't Need an Installer

A typical Mac app is a single, self-contained .app bundle - all of its code and resources live inside that one bundle. Copying it into the Applications folder is the entire installation. There is no separate install program to run, and no registry to write to, because there is no registry on macOS at all.

What Actually Happens When You Delete an App

Dragging an app to the Trash removes only the .app bundle itself. It does not remove:

~/Library/Preferences/*.plist - the app's saved settings file.
~/Library/Application Support/[AppName] - the app's presets, templates, caches, and license or activation data.
Launch Agents - any background helper the app installed to start itself automatically at login.

Over months or years, these leftover files accumulate across every app that was ever tried and later deleted - quietly consuming space, and occasionally causing conflicts if the same app is reinstalled later and finds its old settings still sitting there.

Why Apps Like Hazel Exist

Hazel, and similar utilities such as AppCleaner, watch for the moment you drag an app to the Trash and automatically search the common Library locations for that same app's leftover files, offering to remove everything at once.

This is not a Windows-style uninstaller.
Hazel is not running an uninstall script the way Windows' Add or Remove Programs does - there is no registry to clean on a Mac. It is specifically hunting down the scattered Library files that a simple drag-to-Trash leaves behind.

A Tour of the Utilities Folder

Applications > Utilities holds the built-in tools that manage the Mac itself, rather than doing user-facing work:

The Utilities folder on a real Mac - dozens of small, focused tools live here alongside the ones covered in this unit.

Activity Monitor - shows every running process and how much CPU, memory, energy, disk, and network activity each one is using.
Console - reads the system log, including crash reports and diagnostic messages.
Disk Utility - erases, formats, partitions, and repairs drives.
Audio MIDI Setup - configures connected audio interfaces and shows a map of every MIDI device macOS sees.
Terminal - a text-based, command-line way to interact with macOS directly.
Migration Assistant - transfers accounts, apps, and files from an old Mac or a Time Machine backup to a new one.
Keychain Access - stores and manages saved passwords, certificates, and login credentials.
