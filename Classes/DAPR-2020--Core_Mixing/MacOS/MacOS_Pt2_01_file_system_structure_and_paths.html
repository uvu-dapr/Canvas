macOS File-System Structure and Paths

Every single thing on your Mac's drive lives at a specific, exact address. Learning that address system - where it starts, how it branches, and how to write it down - makes the rest of this unit, and a good chunk of Pro Tools troubleshooting, dramatically easier.

The Root of the Drive: /

Every path on the Mac starts at exactly one place: the root, written as a single forward slash, /. Every folder on the drive, without exception, is either sitting directly inside root or nested inside another folder that eventually traces back to it. Four folders sit right at that root level and matter most for this unit - the same four shown in the screenshot at the top of this unit's first page.

/Applications - apps available to every account on the Mac.
/Library - system-wide settings, support files, and plug-ins shared by every account - a different, visible folder from the hidden one inside your own user folder.
/System - the operating system itself, on a read-only, signed volume since macOS Catalina.
/Users - every account's home folder on this Mac lives here.

Home: ~

Your own personal folder, /Users/yourname, has a shortcut: the tilde, ~. Typing ~/Desktop means exactly the same thing as typing /Users/yourname/Desktop - the tilde always expands to your own home folder, whichever account is currently logged in.

~/Desktop - files and folders visible on your Desktop.
~/Documents - the default save location for most documents.
~/Downloads - where browsers and Mail save downloaded files by default.
~/Music - the default location for Music.app's library and some audio apps' default save folder.
~/Library - hidden by default - your own personal settings and support files, covered in depth on its own page later in this unit.
/Library and ~/Library are genuinely different folders.
They share a name, but they are not the same folder, not aliases of each other, and often hold completely different files for the very same piece of software - one copy shared by everyone, one copy scoped to just you. Confusing the two is the single most common file-system mistake in this entire unit.

What a Path Actually Is

A path is the literal, unambiguous address of a file or folder - a chain of names separated by forward slashes, always starting from either root or home. An absolute path starts with / and spells out the entire route from root: /Users/yourname/Music/song.wav. The same file can be written starting from home instead: ~/Music/song.wav. Both point to the exact same file - they are just two different starting points for writing the same address.

Two tools from the Finder Deep Dive page work together here: the Path Bar reads a path back to you for whatever is selected, and Go to Folder lets you type a path in and jump straight there. Later in this unit, reaching your Pro Tools AAX plug-ins means typing /Library/Application Support/Avid/Audio/Plug-Ins directly into Go to Folder, rather than clicking through five nested windows by hand.
