iCloud, Cloud Files, and Backup

Seeing a file in Finder does not always mean its data is physically sitting on your Mac's drive right now. Understanding the difference - and the separate difference between syncing files and actually backing them up - matters directly for knowing where your session media really lives.

Local Files vs. Cloud-Only Files

A local file's complete data lives on your Mac's own drive, available instantly with no network needed. A cloud-only file has been uploaded to iCloud and then removed from local storage to save space, leaving behind a placeholder that looks identical in Finder but has to be downloaded again before it can actually be opened, played, or edited.

Desktop and Documents Syncing

iCloud Drive can be set to sync your entire Desktop and Documents folders, uploading everything inside them and making that same content available on any other Mac or device signed into the same account. This is convenient, and it is also exactly the setting that most often turns a Pro Tools session folder into a set of cloud-only placeholders without anyone noticing until playback fails.

Finder Settings > General - the Sync Desktop & Documents folders toggle lives right here, off by default on this particular Mac.

Reading the Cloud Status Icons

Finder marks cloud-affected files with small icons next to their names: a small cloud with a down arrow means the file is cloud-only and needs downloading before use, and a small clock or spinning icon means it is actively syncing. A file with neither icon is fully local and available immediately.

The cloud-download icon next to Preview - everything else in this list is fully local, but this one item needs to be downloaded before it can actually be opened.

Know where your session media actually is before you record.
A Pro Tools session that lives inside a synced Desktop or Documents folder can have its audio files silently evicted to cloud-only status by macOS to save local space. Working directly from a session folder outside of iCloud sync, or on an external drive, avoids this risk entirely.

Backup vs. Sync: Not the Same Thing

Syncing keeps one current copy of a file consistent across multiple devices - change it on one Mac, and the same change appears everywhere else almost immediately. That is exactly the problem: if a file is deleted, corrupted, or overwritten by mistake, sync faithfully propagates that mistake everywhere too. A real backup is a separate, historical copy, kept independent of your current working files, specifically so you can go back to a version from before something went wrong.

Time Machine

Time Machine, configured under System Settings > General > Time Machine, is macOS's built-in backup tool. Once a backup disk is selected, it keeps hourly, daily, and weekly snapshots of your entire drive going back over time, letting you restore an individual file - or your whole system - to a specific point in the past. Check that panel to confirm a backup disk is actually configured; a Mac with no backup disk selected here has no Time Machine history at all, regardless of how much gets synced through iCloud.

Time Machine's actual restore view - each stacked window is the same folder as it existed at an earlier point in time, with a timeline on the right for jumping to a specific date.
