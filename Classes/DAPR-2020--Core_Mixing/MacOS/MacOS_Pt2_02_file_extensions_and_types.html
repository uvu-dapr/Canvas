File Extensions and File Types

The letters after the last dot in a filename are not decoration. They are a label telling macOS, and every app on it, exactly how to interpret the data stored inside that file - and macOS hides that label by default.

What an Extension Actually Tells You

An extension is a short suffix - .wav, .zip, .app - that identifies a file's format. Double-clicking a file makes macOS look at its extension to decide which app should open it. The extension is metadata about the file, not the content of the file itself; changing it does not touch a single byte of the actual data inside.

Extensions You'll See Constantly in This Program

.ptx - a Pro Tools session file - the project itself, not the audio inside it.
.wav / .aif / .aiff - uncompressed audio - the standard formats for tracking and mixing.
.mp3 - compressed, lossy audio - fine for reference, not for production work.
.mov / .mp4 - video containers, common for picture-sync work and screen recordings.
.zip - a compressed archive, covered in depth on the Copying, Moving, and Archiving Files page.
.dmg / .pkg / .app - Mac disk images, installer packages, and application bundles, covered in depth on the Installing Software page.
.aaxplugin - Avid's plug-in format for Pro Tools - a package, not a single file, covered on the Library vs. System page.

Turning Extensions On

macOS hides most extensions by default, showing a clean file name instead. Turn this off from Finder > Settings > Advanced, and check Show all filename extensions. With it on, every file in every Finder window shows its true format at a glance - essential for confirming you are about to submit a PDF and not an accidentally-saved .docx.

Enable extensions and confirm it.
Turn on Show all filename extensions in Finder > Settings > Advanced, then open a folder containing a mix of file types and confirm each one now shows its extension.

Show all filename extensions, checked - along with the other Advanced settings covered on the Finder Deep Dive page, like the warning before changing an extension and the search scope default.

Changing an Extension Doesn't Change the File

Renaming song.wav to song.mp3 does not compress or re-encode a single sample of audio. The file's actual content - the raw audio data inside - is completely untouched; only the label changed. What usually happens next is that whichever app tries to open it gets confused, because the label now promises a format the data does not actually match, and the file either fails to open or opens as garbled noise. The only way to actually convert a file's format is to export or bounce it through an app that reads the original format and writes a new file in the target format - renaming is never a substitute for conversion.
