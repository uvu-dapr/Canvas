Hardware, Software, and Firmware

These three words get used loosely, but they describe three genuinely different layers of a working computer, and mixing them up leads directly to troubleshooting the wrong thing.

Hardware

Hardware is the physical, touchable equipment - the CPU, the RAM chips, the storage drive, the ports on the side of the Mac, the audio interface sitting on your desk. Hardware cannot be updated with a download; it can only be repaired or replaced.

Software

Software is the set of instructions running on that hardware, from the operating system itself down to a single app. macOS is software. Pro Tools is software. A plugin is software. Software is what gets installed, updated, and uninstalled.

Firmware

Firmware is a special layer of software written directly onto a hardware component itself, controlling how that specific piece of hardware boots and behaves before the operating system ever loads. It usually does not change unless the manufacturer issues a firmware update.

Your Mac's own firmware - controls the boot process before macOS starts loading at all.
An audio interface's firmware - controls how that interface communicates over USB or Thunderbolt, running on the interface itself - separate entirely from the driver, which is software running on the Mac.
Why this distinction matters in troubleshooting.
Reinstalling a driver only changes the software layer running on the Mac. If an interface is behaving oddly, checking the manufacturer's site for a firmware update addresses a completely different layer, and one that a driver reinstall cannot touch.

A Quick Comparison

Hardware - physical equipment. Updated by replacement, not download.
Software - instructions running on hardware. Installed, updated, and uninstalled freely - macOS, Pro Tools, and every plugin all count.
Firmware - software built into a specific piece of hardware, controlling its lowest-level behavior. Rarely updated, and only through a process the manufacturer provides.
