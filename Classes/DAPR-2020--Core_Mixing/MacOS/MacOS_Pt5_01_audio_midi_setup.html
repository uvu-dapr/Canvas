Audio MIDI Setup: Devices, Aggregates, and MIDI Studio

Audio MIDI Setup is the one built-in Mac utility every DAPR student needs to actually open and use, not just know about. It has two entirely separate windows, and knowing MIDI Studio without ever touching Audio Devices means missing the half of this app that controls your actual interface.

The Audio Devices Window

Open Audio MIDI Setup from Applications > Utilities, and make sure the Audio Devices window is the one showing - Window > Show Audio Devices if it is not already in front. This window lists every audio device macOS currently sees, and selecting your interface here reveals exactly how it is configured.

Input channels - how many separate input sources the interface provides.
Output channels - how many separate output destinations the interface provides.
Sample rate - how many times per second the interface captures or plays audio, set here for the system as a whole.
Bit depth - how much resolution each individual sample carries, also configured here per device.
Clock source - which device is acting as the master timing reference, on interfaces that support more than one clock source.
System input / System output - the two devices macOS itself defaults to for input and output, chosen from the same window.
This is mandatory - MIDI Studio alone does not satisfy this requirement.
Open Audio Devices, select your actual connected interface, and screenshot the window with input channels, output channels, and sample rate all visible.

Aggregate Devices and Multi-Output Devices

Aggregate Device - combines multiple separate audio interfaces into one single logical device that other apps see as though it were one piece of hardware - useful when you need more total channels than any one interface provides on its own.
Multi-Output Device - routes the same audio out to multiple hardware outputs at once - useful for sending the same signal to both a set of studio monitors and a separate recording input simultaneously.

Both are built from the + button in the lower-left of the Audio Devices window. Neither one is something this unit requires you to permanently configure, but understanding what each does explains a setup you will eventually encounter in a lab or a session that already has one built.

Combining interfaces means their clocks have to agree.
An Aggregate Device only works reliably when every interface inside it is set to the same sample rate, and ideally shares a single clock source. Mismatched sample rates between combined devices is the single most common cause of clicks, pops, or drift in an aggregate setup - drift correction, a setting inside the Aggregate Device editor, exists specifically to compensate for small timing differences between devices that cannot share a hardware clock.

A real multi-channel routing example from Dolby Audio Bridge, a virtual audio device - each output channel gets mapped to a specific speaker position. A Multi-Output Device follows the same underlying idea: specific channels routed to specific physical destinations, not just a single stereo pair.

MIDI Studio

MIDI Studio is a separate window from Audio Devices - switch to it with Window > Show MIDI Studio - showing a visual map of every MIDI device and driver macOS currently recognizes, from physical MIDI interfaces to virtual, software-only connections like Bluetooth MIDI and the IAC Driver. It exists to configure MIDI routing specifically, and has nothing to do with audio channel counts or sample rate - the two windows genuinely do not overlap in function.
