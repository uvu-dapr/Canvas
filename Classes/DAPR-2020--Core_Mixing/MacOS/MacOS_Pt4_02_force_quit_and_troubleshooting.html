Force Quit and Troubleshooting

A frozen app is not a reason to hold down the power button. macOS has a graduated set of tools for exactly this situation, each one more forceful than the last, and working through them in order solves almost everything without ever risking an unclean shutdown.

Getting There Fast: Option-Command-Escape

Option-Command-Escape opens the Force Quit Applications window immediately, skipping the Apple menu entirely. It lists every running app; selecting one and clicking Force Quit ends it right away, without waiting for that app to finish whatever it was doing.

The Force Quit Applications window - select an app from the list and click Force Quit. Note the reminder at the bottom: this exact window opens with Option-Command-Escape.

Five Levels, From Gentlest to Last Resort

Quit (Command-Q) - asks the app to close itself normally, saving anything it needs to first. This only works if the app is still responding.
Force Quit (Option-Command-Escape) - ends an unresponsive app immediately, with no chance to save unsaved work in that app - use this once Quit has failed to do anything for a few seconds.
Activity Monitor Quit - select the process in Activity Monitor, click the X button, and choose Quit - functionally the same gentle request as Command-Q, just reachable when the app itself is too frozen to show a Quit menu.
Activity Monitor Force Quit - the same button's more forceful option - ends the process immediately, useful when a background process with no visible window or Dock icon needs to be stopped.
Restart the Mac - the last resort, reserved for when the whole system - not just one app - has stopped responding to any of the above.

A Sensible Order to Actually Follow

Try Command-Q first and give it a few seconds - many apparent freezes are just a slow save or a large file operation finishing. If nothing happens, move to Option-Command-Escape and Force Quit that one app. If the app does not even appear in the Force Quit list, or a background process is the actual problem, open Activity Monitor and end it from there. Reach for a full restart only when the Mac itself has stopped responding to input at all, not as the default first move for a single stuck app.

Holding the power button is not a normal troubleshooting step.
Holding the power button forces an unclean shutdown of the entire Mac, not just the frozen app, and skips every safety step macOS normally takes when closing files and sessions. Reserve it for when the Mac is completely unresponsive to everything else on this page - not as a shortcut for a single misbehaving plugin window.
