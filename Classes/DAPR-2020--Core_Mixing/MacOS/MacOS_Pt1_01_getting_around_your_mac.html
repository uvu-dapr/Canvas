Getting Around Your Mac

Pro Tools sits on top of macOS, and macOS has its own set of keyboard modifiers, hidden folders, and system settings that change how Pro Tools behaves. This lab walks you through the five pieces of Mac navigation every mixer needs: Finder modifier keys, the Function key toggle, hiding background windows, telling Sound Preferences apart from Pro Tools Preferences, and finding the Library folder where your plug-ins and background helper processes actually live.

Goals

  • Use Finder modifier keys to select, copy, and move files with precision.
  • Set the Function key toggle so your F-keys work as Pro Tools key commands, not media controls.
  • Hide every window except your active app with a single shortcut.
  • Explain the difference between macOS Sound Preferences and the Pro Tools Playback Engine.
  • Locate your Library folder, your installed plug-ins, and your Launch Agents and Launch Daemons.

Step 1: Finder Modifier Keys

Every modifier key changes what a click or a drag does in Finder. Learn these five and file management stops being guesswork.

Click - selects one file and deselects everything else.
Shift + Click - selects every file between your last click and this one.
Command + Click - adds or removes individual files from the selection without touching the rest.
Option + Drag - copies the file to the destination instead of moving it. Use this when dragging within the same drive.
Command + Drag - forces a move instead of a copy. Use this when dragging between two different drives, since Finder copies across drives by default.
Note: Control + Click opens the same contextual menu as a right-click. Every Mac trackpad and mouse supports this even without a right-click button configured.

Step 2: The Function Key Toggle

Pro Tools puts key commands on F1 through F12. macOS ships with those same keys set to control volume, brightness, and media playback instead. Set the toggle below once, and your F-keys work directly in Pro Tools.

Without this setting, your F-keys turn into media keys.
Pressing F1 lowers your screen brightness instead of triggering the Pro Tools command mapped to it. To get the true F-key signal through without changing this setting, you would have to hold Fn every single time - that is not workable mid-session.
  1. Open System Settings.
  2. Click Keyboard in the sidebar.
  3. Click Keyboard Shortcuts.
  4. Select Function Keys in the left-hand list.
  5. Check Use F1, F2, etc. keys as standard function keys.
  6. Close System Settings.

The Function Keys panel with the toggle switched on - this is exactly what your own screenshot for this step should show.

Tip: With this setting on, the two functions swap places. Your F-keys now send standard F1-F12 signals to Pro Tools directly. Hold Fn at the same time as an F-key to get the media function (volume, brightness, play/pause) back.

Step 3: Hide Other Windows

A mix session fills your screen with plugin windows, browsers, and Finder windows. One shortcut clears everything except your active app.

Command + H - hides the windows of the app you are currently in.
Command + Option + H - hides every other open app and leaves only your active app's windows on screen.
Note: Find the same command in the menu bar under the app name's menu, listed as Hide Others.

Step 4: Sound Preferences vs. Pro Tools Preferences

macOS Sound settings and the Pro Tools Playback Engine are two completely separate audio paths. Changing one does not change the other.

These two settings control different things:

System Settings > Sound sets the device macOS uses for system alerts, notifications, and any non-Pro-Tools audio, such as a browser tab.

Pro Tools > Setup > Playback Engine sets the audio interface Pro Tools uses for your session. This is independent of the macOS Sound setting.

Set your interface in Playback Engine for every Pro Tools session. The macOS Sound output can stay on the Mac's built-in speakers for everything else - the two settings will not conflict.

The macOS Sound pane's Output list on a real production Mac - notice how many virtual devices show up here (Pro Tools Audio Bridge, Dolby Audio Bridge, and more) alongside the actual hardware. None of these are selected in Playback Engine automatically just because they appear here.

Step 5: Library, Plug-Ins, and Launch Agents

Your plug-ins, and the background processes that authorize them, live inside the Library folder. macOS hides this folder from you by default.

Reveal your user Library folder:
In Finder, open the Go menu, hold Option, and click Library once it appears in the list. Or use Go > Go to Folder and type ~/Library.
/Library/Audio/Plug-Ins/ - plug-ins installed for every user account on the machine (System Library).
~/Library/Audio/Plug-Ins/ - plug-ins installed for your user account only (User Library).
~/Library/LaunchAgents and /Library/LaunchAgents - background helper processes that start when a single user logs in. iLok, interface drivers, and plug-in license managers install these.
/Library/LaunchDaemons - background processes that start at the system level, before any user logs in. These run system-wide services rather than per-user apps.
Tip: When a plug-in or interface will not authorize, check its Launch Agent or Launch Daemon first. A stalled background helper process is the most common cause.
