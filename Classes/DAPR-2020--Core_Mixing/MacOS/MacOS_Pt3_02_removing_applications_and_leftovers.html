Removing Applications and Leftovers

Most Mac software installs itself with a single drag, and uninstalls with a single delete - but that simplicity hides a few files that get left behind every time. Knowing where those files go, and when to use something more thorough than the Trash, keeps a Mac clean over years of installing and removing audio software.

Why Most Mac Apps Don't Need an Installer

A typical Mac app is a single, self-contained .app bundle - all of its code and resources live inside that one bundle. Copying it into the Applications folder is the entire installation. There is no separate install program to run, and no registry to write to, because there is no registry on macOS at all.

What Actually Happens When You Delete an App

Dragging an app to the Trash removes only the .app bundle itself. It does not remove any of the following:

Applications - the .app bundle itself - the only thing a simple Trash drag actually removes.
~/Library/Preferences - the app's saved settings file, one small .plist per app.
~/Library/Application Support - presets, templates, caches, and license or activation data - scoped to your account.
/Library/Application Support - the same kind of data, but shared system-wide across every account.
Plug-in locations - Audio Unit, VST, and AAX plug-ins the app installed, which do not live inside the app itself and are never touched by deleting it.
LaunchAgents and LaunchDaemons - background helpers the app installed to run automatically, covered in full on the Login Items, Launch Agents, and Launch Daemons page.

Over months or years, these leftover files accumulate across every app that was ever tried and later deleted - quietly consuming space, and occasionally causing conflicts if the same app is reinstalled later and finds its old settings still sitting there.

When to Use a Manufacturer's Uninstaller Instead

Professional audio software that installs drivers, kernel-level components, or Launch Daemons often ships its own dedicated uninstaller app precisely because a simple Trash drag cannot cleanly reverse that kind of install. Apogee's Control 2 installer, covered on the Installing Software page, is a real example - it includes a Software Uninstaller app alongside its installer specifically so a driver-level install has a clean, complete way back out. When an uninstaller is provided, use it instead of dragging the app to the Trash.

Why Apps Like Hazel Exist

Hazel, and similar utilities such as AppCleaner, watch for the moment you drag an app to the Trash and automatically search the common Library locations for that same app's leftover files, offering to remove everything at once.

This is not a Windows-style uninstaller.
Hazel is not running an uninstall script the way Windows' Add or Remove Programs does - there is no registry to clean on a Mac. It is specifically hunting down the scattered Library files that a simple drag-to-Trash leaves behind, and it is a different tool from a manufacturer's dedicated uninstaller.
