External Drives, Volumes, and File Systems

Before formatting a drive in Disk Utility, it helps to know what Finder is actually showing you when a drive gets plugged in - the words disk, drive, volume, and partition all mean slightly different things, and mixing them up makes troubleshooting a connection problem harder than it needs to be.

Disk, Drive, Volume, and Partition

Disk / Drive - the physical piece of hardware itself - an internal SSD, an external hard drive, a USB stick.
Volume - a formatted, usable storage area that shows up in Finder with its own name and icon. One physical drive can hold one volume, or several.
Partition - the act of splitting one physical drive into multiple separate volumes, each formatted independently.

Mounting and Ejecting

Connecting an external drive mounts it automatically - macOS reads its volumes and adds each one to the Finder sidebar with its own eject icon. Always eject a drive before physically disconnecting it, using that icon, Command-E, or dragging its icon to the Trash, which turns into an Eject symbol during the drag. Ejecting flushes any data still waiting to be written and closes out the file system cleanly; unplugging a drive that is mid-write, without ejecting first, is one of the most common causes of a corrupted volume or a Pro Tools session that can no longer be opened.

What Disk Utility Does

Erase - wipes a drive and formats it with a file system you choose - this is where you set APFS, exFAT, and the rest.
Partition - splits one physical drive into multiple separate volumes, each with its own file system if needed.
First Aid - checks a drive's directory structure for errors and repairs what it can, without erasing your data.
Create/mount a disk image - builds or opens a DMG - the same disk image format covered on the installers page.

A Short History of File Systems

FAT16 - the original MS-DOS format from the 1980s, capped around 2GB per volume. No longer used on modern drives.
FAT32 - introduced with Windows 95 OSR2. Fixed the volume-size limit, but capped every single file at 4GB. Still shows up today as the default format on SD cards, USB drives, and camera memory.
exFAT - built specifically to replace FAT32 on flash drives. No 4GB file-size limit, and both macOS and Windows read and write it natively - the practical default for a drive shared between the two operating systems.
NTFS - Windows' native, journaled file system since Windows 2000. macOS reads an NTFS drive out of the box but cannot write to it without third-party software.
HFS+ (Mac OS Extended) - Apple's format from 1998 through 2017. Journaled, and case-insensitive by default.
APFS - Apple's current default since 2017, built for flash storage and SSDs. Adds native encryption, near-instant space-efficient snapshots, and stronger crash protection than HFS+. Every new Mac ships formatted this way.

The 4GB file-size cap is the most common surprise.
A FAT32-formatted SD card or USB drive will refuse to copy a single exported video or a large session bounce onto it if that file is larger than 4GB - the drive itself is not broken, the file system just cannot hold a file that size.

Choosing a Format in Disk Utility

Mac-only external SSD or drive - format as APFS.
Drive shared between a Mac and a Windows PC - format as exFAT.
Any drive that needs to hold files larger than 4GB - never format as FAT32.
Tip: Run First Aid on a drive first whenever Pro Tools reports that it cannot read or write session files correctly - a directory error is a common, fixable cause.
