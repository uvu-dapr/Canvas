Copying, Moving, and Archiving Files

Dragging a file feels like the simplest thing you can do on a Mac, but what actually happens - a copy or a move - quietly depends on where you drag it, and getting that wrong is one of the most common causes of a Pro Tools session that suddenly can't find its own audio.

Same Drive vs. Different Drive

Dragging a file within the same drive moves it - the file leaves its original folder entirely and exists only in the new location. Dragging a file to a different drive copies it instead - the original stays exactly where it was, and a second, independent copy appears in the new location. Same gesture, two different outcomes, decided entirely by whether the destination is on the same physical drive.

Forcing the Opposite with Option

Holding Option while dragging within the same drive forces a copy instead of a move, leaving the original untouched. There is rarely a need to force a move across drives, since that is already the default there - Option-drag matters almost exclusively for same-drive copying.

Duplicating and Aliases

Command-D - duplicates the selected item in place, appending "copy" to its name.
Alias - a lightweight pointer to the original file, covered in full on the Files, Folders, Applications, Packages, and Aliases page - not the same thing as a duplicate.

The Trash: Deleting, Restoring, Emptying

Moving a file to the Trash does not delete it - it relocates the file into a holding folder, still fully recoverable. Right-click any item in the Trash and choose Put Back to restore it to its original location. Nothing is actually deleted, and no space is reclaimed, until you choose Empty Trash, which asks for confirmation before permanently removing everything inside.

Moving session audio outside its expected location breaks the session.
Pro Tools sessions reference their audio files by location. Moving, renaming, or relocating a source WAV file outside the Audio Files folder Pro Tools expects it in produces a missing-file warning the next time that session opens, forcing a manual relink before playback works again. When in doubt, leave session media exactly where it was recorded or imported.

ZIP Archives

Right-click any file or folder and choose Compress to create a .zip archive - a single file containing a compressed copy of everything selected. The original folder is untouched; the .zip is an entirely separate file sitting alongside it. Double-clicking a .zip extracts its contents into a new folder, decompressed and ready to use, again without touching the .zip file itself. Always open the extracted folder and confirm every expected file is present and plays back correctly before deleting either the original folder or the .zip - a corrupted archive fails silently far more often than it fails loudly.

The right-click context menu with Compress selected - macOS names the resulting .zip after the folder automatically, leaving the original folder completely untouched alongside it.

The finished archive - a completely separate file from the original folder, with its own size on disk.
