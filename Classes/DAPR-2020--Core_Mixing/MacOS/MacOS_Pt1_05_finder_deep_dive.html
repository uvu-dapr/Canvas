Finder Deep Dive

Finder is the single app every other piece of Mac navigation eventually routes through. Most of what makes it fast is turned off by default or hidden behind a menu most people never open - this page turns all of it on.

The Sidebar

Favorites - any folder you drag into this section for one-click access - your session folder, a scratch drive, anything you open constantly.
Locations - This Mac, iCloud Drive, and any connected server all live here automatically.
External drives - appear in the sidebar automatically the moment they are connected, with an eject icon next to each one.

Four Ways to View a Folder

Icon View - best for visually scanning thumbnails - picking out an image or a waveform preview by eye.
List View - best for sorting by name, date, or size, and for scanning a long list of session files at once.
Column View - best for drilling down through several nested folders quickly, since each click adds a column instead of replacing the window.
Gallery View - a large preview pane plus a filmstrip - useful for previewing several files back to back without opening each one.

Sorting, Grouping, and Searching

Click any column header in List View to sort by it - clicking Date Modified twice puts the most recent files at the top. The View menu's Group By option clusters files by kind, date, or tag without changing the sort order underneath. The search field in the top right defaults to searching This Mac; a small scope bar lets you narrow it down to just the current folder instead.

View Options (Command-J) for a specific folder - Group By, Sort By, and exactly which columns show up in List View, all set per-folder rather than globally.

Reading a Window Without Opening Anything

Preview pane - turned on from View > Show Preview - shows a live preview of whatever is selected, alongside file details, without opening it.
Status Bar - shows item count and free space at the bottom of the window.
Path Bar - turned on from View > Show Path Bar - shows the exact nested-folder route to whatever is selected, as a row of clickable segments at the bottom of the window.
Turn on the Path Bar and actually read it.
The path bar is not decoration - it is the literal address of the selected item, one folder inside the next. Clicking any segment jumps straight to that folder. Enable View > Show Path Bar now and click through a few segments before moving on.

The Path Bar in action at the bottom of a real Finder window - Macintosh HD, then Library, then Audio, each segment clickable.

Get Info and Finder Settings

Command-I on any selected file opens Get Info - size, kind, exact location, tags, and a Sharing & Permissions section covered in depth on the Privacy and Security page. Finder's own preferences live under Finder > Settings, split into General, Tabs, Sidebar, and Advanced tabs. Advanced is where filename extensions and iCloud removal warnings are controlled, covered next on the File Extensions and File Types page.

Showing Hidden Files

Shift-Command-. toggles whether hidden files and folders - anything starting with a dot, like .DS_Store - are visible in the current Finder window. These files exist for a reason and are hidden on purpose; toggling them visible for troubleshooting is fine, but nothing here should be deleted without knowing exactly what it does first.

Go to Folder

Shift-Command-G opens a small text field where typing any path - ~/Music, /Library/Audio, or anything else - jumps directly there, instantly. This is dramatically faster than clicking through several nested folders by hand, and it is the standard way to reach folders, like the hidden user Library, that Finder does not show a shortcut to.

Go to Folder, mid-type - notice the autocomplete offering nearby matching folders below the typed path, a fast way to catch a typo before pressing Return.
