Library vs. System: Pro Tools and Your Files

At the root of the drive, Library and System look like similar folders, but they hold entirely different kinds of content. This page goes past the basics into what actually lives inside them - especially the parts that matter for audio work.

Two Different Library Folders, Quickly Recapped

/Library - visible in Finder by default, shared by every account on the Mac.
~/Library - hidden by default, and scoped to your own user account only. Reveal it from the Finder Go menu by holding Option.

Inside Application Support

Application Support is where an app stores larger, persistent data that goes beyond a simple settings file - custom presets, templates, caches, license data, and helper-app files.

/Library/Application Support, showing one folder per company or piece of software that installed something system-wide.

Effectively, this is a shared filing cabinet - one folder per vendor. The per-user version, ~/Library/Application Support, holds the same kind of data but scoped to a single account only.

Inside Library/Audio

Both /Library/Audio and ~/Library/Audio hold the files CoreAudio and CoreMIDI - the audio and MIDI engines built into macOS - actually use:

Plug-Ins/Components - Audio Unit (AU) format plug-ins.
Plug-Ins/VST and VST3 - VST-format plug-ins, stored alongside the AU folder.
MIDI Drivers - drivers for MIDI interfaces.
Sounds - system alert sound files.
Apple Loops - loop content used by GarageBand and Logic.

Library/Audio on a real, actively-used Mac - considerably more than the short list above once every plug-in and driver installer has added its own folder.

This is the actual, physical home of every plug-in a DAW can load. If a plug-in is not showing up in Pro Tools, checking whether its files genuinely exist inside this folder is a direct, filesystem-level check - separate from anything a driver or a Launch Agent controls.

Pro Tools' AAX Plug-In Location

AAX is Avid's own plug-in format, built specifically for Pro Tools, and it lives in a specific, dedicated location rather than the general Plug-Ins folder covered above:

/Library/Application Support/Avid/Audio/Plug-Ins - every AAX plug-in Pro Tools can currently load.
/Library/Application Support/Avid/Audio/Plug-Ins (Unused) - a holding folder Pro Tools uses when a plug-in is deliberately disabled without being deleted. A plug-in sitting here will not appear in Pro Tools until it is moved back into the main Plug-Ins folder.

AU and VST/VST3 plug-ins use entirely different locations and formats from AAX - the ones already covered above under Library/Audio - which is why the same plug-in from the same manufacturer sometimes has to be installed once for Pro Tools and separately again for a different DAW.

Navigate there yourself using Go to Folder.
Press Shift-Command-G, type /Library/Application Support/Avid/Audio/Plug-Ins, and press Return. Screenshot the resulting window showing your installed AAX plug-ins - this reinforces both the Go to Folder skill from earlier in this unit and exactly where Pro Tools' plug-ins actually live.

Go to Folder navigating straight to the AAX Plug-Ins folder, with dozens of real .aaxplugin files visible - and the neighboring Plug-Ins (Unused) and Plug-Ins - Archive folders mentioned above, right where this page says they would be.

Pro Tools: User Files vs. System-Wide Files

Pro Tools itself is the clearest real example of the /Library vs. ~/Library split covered throughout this unit. Its AAX plug-ins, covered above, live in /Library - shared by every account on the Mac, since any user should be able to load the same plug-ins. Pro Tools' own preferences, custom key command sets, and per-user settings, on the other hand, live inside ~/Library/Application Support and ~/Library/Preferences - scoped to your account alone, so two different logins on the same Mac can each have their own personalized Pro Tools setup without interfering with each other.

This is not a trivia detail specific to one app - it is the same system-wide-vs-personal split every piece of software on the Mac follows, just made concrete with software you will use every day in this program.
