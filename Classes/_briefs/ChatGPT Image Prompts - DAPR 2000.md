# ChatGPT Image Prompts: DAPR 2000 Digital Audio Essentials

Written 2026-09-24 for the v65 build. Each file below already exists as a code drawn placeholder (a gray panel with one sine wave, no text) and is already linked from its page, so nothing needs relinking.

**How to use this file**

1. Run each prompt on its own in ChatGPT. One image per prompt.
2. Save the result over the exact file shown, same name, same folder.
3. Check the file size when you save it. The PNG cap is 1 MB. If one comes out larger, tell me and I will re-export it at the same size and name.
4. Commit and push so the raw GitHub links go live before the sandbox import.

House rules for every prompt: photorealistic, no text, no numbers, no labels, no logos, no brand marks, no legible screens, no real product you could name.
