# DAPR 2000 - Digital Audio Essentials: ChatGPT Image Requests

Five images in the course are code drawn placeholders: a gray panel with one sine wave. Replace all five. Nothing else in the course uses a placeholder. The other drawn images (Term Timeline, Three Checks, polar patterns, pre-delay, true peak, filter slopes) are real teaching diagrams and stay.

Each page already links the file and its alt text already describes the picture below. So the new image has to match that alt text. Save it over the same file, with the same name, in the same folder, and nothing needs relinking.

## How to do each one

1. Paste the prompt into ChatGPT. Make one image per chat.
2. Ask for a wide landscape image. ChatGPT cannot make exactly 1600 x 600, and that is fine.
3. Save the PNG over the path shown, with the same name.
4. When all five are saved, tell me. I will crop each to 1600 x 600, keep it under 1 MB and keep the name. Then you commit and push.

These rules are already written into every prompt: photorealistic, no text, no numbers, no labels, no logos, no brand marks, no legible screens and no real product you could name.
