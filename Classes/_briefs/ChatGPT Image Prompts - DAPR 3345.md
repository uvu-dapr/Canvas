**How to use this file**

1. Run each prompt on its own in ChatGPT. One image per prompt.
2. Save the result over the exact file shown.

House rules: no text, no numbers, no labels, no logos, no brand marks, no legible screens, no real product you could name.

All 27 page images are 1600 x 600. Image 28 is 1600 x 667 to keep the shape of the banner it replaces.
