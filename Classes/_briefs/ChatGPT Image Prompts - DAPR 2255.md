# ChatGPT Image Prompts: DAPR 2255 Audio Hardware I

Written 2026-09-24 for the v81 build.

These six pages currently pass the image gate only because they share their one image with another page. Rule 11 says a shared image is the next thing to improve, and rule 13 says to start with exactly these. None of the files below exists yet and none is linked from a page. Once you save and push them I will link all six and ship v82.

**How to use this file**

1. Run each prompt on its own in ChatGPT. One image per prompt.
2. Save the result to the exact path shown, same name, same folder. Create the folder if it does not exist.
3. Check the file size when you save it. The PNG cap is 1 MB. If one comes out larger, tell me and I will re-export it at the same size and name.
4. Commit and push so the raw GitHub links go live, then tell me and I will link them and rebuild.

House rules for every prompt: photorealistic, no text, no numbers, no labels, no logos, no brand marks, no legible screens, no silkscreen printing, no numbered connector faces, no real product you could name.
