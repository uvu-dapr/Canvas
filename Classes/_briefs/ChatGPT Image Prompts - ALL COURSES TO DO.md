# ChatGPT Image Prompts: All Courses To Do

Written 24 September 2026. One list for all seven DAPR courses. It holds only images that still need making: files that are missing, files that are still a code drawn gray placeholder, and figures a page links that never had a prompt. Everything else in the per course prompt files is already a real image and is left out.

## How to use

1. Open a new ChatGPT chat for each image. One image per chat.
2. Paste the prompt from the gray box. Ask for a wide landscape image if ChatGPT offers a shape.
3. Save the PNG over the path shown under Save as, with the same name, in the same folder. Create the folder if it does not exist.
4. Tell Claude which ones you saved. Claude crops each to 1600 by 600 (or the size noted on the item), keeps it under 1 MB and keeps the name. Then commit and push.

Every prompt already says: no text, no numbers, no labels, no logos, no brand marks, no legible screens, and no real product you could name.
