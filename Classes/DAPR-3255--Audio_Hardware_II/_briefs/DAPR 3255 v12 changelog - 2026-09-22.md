## 8. Two new preflight rules, and one that was a false accuser twice

| Rule | What it catches |
|---|---|
| **10b** | A page image served from anywhere but the course repo. Rule 10 had only ever checked quiz images |
| **10c** | A text node sitting in the body inside no element at all, which is what a stripped inline diagram leaves behind |

10c took three attempts and the first two are worth recording, because the shape
repeats. A line based test flagged 43 terminal commands and ASCII diagrams inside
`<pre>`. Stripping `<pre>` still left 4, because this package puts commands in a
styled `<div>` rather than `<pre>`. Only a structural test is right: parse the
page and ask whether the text is inside any element. Both rules proved by making
them fail on purpose.
