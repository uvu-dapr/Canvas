This folder contains images extracted from Pro Tools 2026.4.1 Reference Guide
and Pro Tools What's New PDFs (2024.10 through 2026.4). Each subfolder is a
DAPR 3340 topic slug that matches the Images/<topic>/ layout.

These are staged for instructor review, not yet promoted into the topic folders
proper. Per Canvas Standards Section 8.1 Image quarantine, this is a review
holding area, not a resting place. Once reviewed, the useful images should be
moved directly into Images/<topic>/ and this folder deleted.

Filename pattern:
  <feature-slug>-p<page-number>-<image-index>.<ext>
where page-number is the PDF page and image-index is the pdfimages sequence
number.
