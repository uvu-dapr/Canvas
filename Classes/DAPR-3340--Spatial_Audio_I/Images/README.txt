FACTUAL REFERENCES USED
-----------------------

ITU-R BS.2051-3:
- Sound System I (0+7+0)
- L/R: 30-45 degrees
- Lss/Rss: 85-110 degrees
- Lrs/Rrs: 120-150 degrees
- Same-side side/rear separation: 30-60 degrees

Dolby Pro Logic II:
- Pro Logic IIx adds back surround channels for 7.1 playback.
- Pro Logic IIz adds two front height channels.

Sony SDDS:
- Historical 8-channel layout used five screen channels, two surrounds, and LFE.
- This is different from the modern side/rear 7.1 arrangement.

Windows Media Audio 9 Professional:
- Microsoft documented discrete multichannel playback including 5.1 and 7.1.
- Up to 24-bit / 96 kHz.
- M3 device template allowed up to 7.1, 96 kHz, and 1.5 Mbit/s.

Microsoft Spatial Sound:
- Platform-level spatial audio system for Windows/Xbox/HoloLens.
- Supports surround and elevation cues.
- Supports static channels and dynamic audio objects.
- It is not the same technology as Windows Media Audio.

Auro-3D:
- Auro documents 7.1-based immersive layouts including 7.1.2 and Auro 11.1 (7.1+4H).
