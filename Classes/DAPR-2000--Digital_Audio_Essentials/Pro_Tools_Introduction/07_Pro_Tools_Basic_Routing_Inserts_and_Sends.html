Pro Tools: Basic Routing with Inserts and Sends

Routing determines where a signal comes from, where it goes, and which processing it passes through. Inputs and outputs define the main path. Inserts process the signal in series on a track. Sends create additional routes to buses or hardware outputs.

Goals

  • Trace the main signal path through an Audio track.
  • Assign hardware inputs, hardware outputs, and internal buses.
  • Explain the difference between an insert and a send.
  • Build a shared reverb with a send, bus, and Auxiliary Input.
  • Explain how sends create headphone cue mixes.

The Main Signal Path

Physical source → interface input → track input → inserts → fader and pan → track output → interface output → headphones or monitors

A track needs an assigned hardware input to record a physical source. It needs an assigned and mapped output path to be audible through an interface output. A track can also receive from or send to internal buses instead of physical connectors.

No Output means no audible main path
A track assigned to No Output can still feed a send, but its main output will not be heard. When a track meter moves but nothing is audible, inspect the track output and the output mapping in I/O Setup.

Find Routing Controls

In the Mix window, routing controls appear near the top of each channel strip. In the Edit window, use the Edit Window View selector to show Inserts A-E, Sends A-E, and I/O.

Inserts and Sends

Inserts Compared with Sends
Feature Insert Send
Signal relationship The track signal passes through the processor in series An additional copy is routed to a bus or hardware output
Return path Returns automatically to the same track Must reach an Auxiliary Input, Audio track, Instrument track, or hardware destination
Typical control Plugin settings and bypass Send level, pan, mute, and pre-fader or post-fader status
Common use EQ, compression, gating, or processing intended for the entire track signal Shared reverb, shared delay, parallel processing, or a headphone cue mix

Insert Signal Flow

Track audio → Insert A plugin → Insert B plugin → track fader → output

Pro Tools provides up to ten insert slots, A-E and F-J, on Audio, Auxiliary Input, Master Fader, and Instrument tracks. Inserts on Audio, Auxiliary Input, and Instrument tracks are pre-fader. Master Fader inserts are post-fader.

Send and Return Signal Flow

Audio track send → internal bus → Auxiliary Input → effect insert → main output

The original Audio track continues to its main output while the send routes an additional copy to the effect path. This parallel structure lets several tracks share one processor while each track has its own send level.

Build a Shared Reverb

  1. Create a stereo Auxiliary Input and name it Reverb Return.
  2. Create or select a stereo internal bus and name it Reverb.
  3. Set the Reverb Return input to the Reverb bus.
  4. Set the Reverb Return output to the main stereo output.
  5. Insert a reverb plugin on the Reverb Return and set the plugin mix to 100 percent wet.
  6. On each source track that needs reverb, assign a send to the Reverb bus.
  7. Use each source track's send level to control how much of that source reaches the reverb.
  8. Use the Reverb Return fader to control the overall reverb level in the mix.
Set a send-and-return effect to 100 percent wet
The dry signal already reaches the main output from the source track. The Auxiliary Input should return only the effect. Mixing dry signal into the return can change level and make the routing harder to control.

Pre-Fader and Post-Fader Sends

  • A post-fader send follows changes made with the source track fader. This is the common starting point for reverb and delay because the effect follows the source level.
  • A pre-fader send is independent of the source track fader. This is useful when a headphone mix or parallel path must remain separate from the control-room mix.
Choose send type according to the relationship you need
Use post-fader when the additional path should follow the main mix. Use pre-fader when it should remain independent. Do not choose pre-fader or post-fader by habit without considering what should happen when the source fader moves.

Use Sends for a Headphone Cue Mix

A cue mix is a separate monitor mix for a performer. Source tracks can keep their main outputs routed to the control-room mix while sends feed another pair of interface outputs connected to a headphone system. Each send level creates the performer's balance without requiring changes to the main mix.

  1. Confirm which interface output pair feeds the headphone system.
  2. Assign a send from each needed source track to that cue output or to a cue bus that reaches that output.
  3. Choose post-fader sends when the cue should follow the main mix with small level adjustments.
  4. Choose pre-fader sends when the performer needs a mix independent of the main faders.
  5. Balance the send levels while the performer listens through the headphones.
  6. Control the cue output's overall level with its hardware headphone control or an assigned Master Fader.
Avoid delayed monitoring paths while recording
High-latency plugins and complex routing can make a performer hear a delayed version of the live source. Keep the record and cue path simple, use low-latency processing, or use the interface's direct-monitoring system when instructed.
