Pro Tools: Tracks and New Track Setup

A Pro Tools track is more than a lane on the screen. Its type determines whether it can record audio, store MIDI, host a virtual instrument, receive a bus, organize other tracks, or control the level of an output path.

Goals

  • Select the correct track type for a specific task.
  • Choose mono or stereo according to the source and signal path.
  • Distinguish sample-based and tick-based timebases.
  • Create several track types in one New Tracks dialog.
  • Name tracks clearly before recording.

Basic Track Types

Basic Pro Tools Track Types
Track Type What It Does Common Use
Audio Records audio to disk and plays recorded or imported audio clips Voice, guitar, drums, sound effects, or music files
MIDI Records and plays MIDI performance data but does not carry audio Controlling an external MIDI device or routing MIDI separately
Instrument Combines MIDI performance controls and an audio channel strip Playing a virtual instrument plugin
Auxiliary Input Receives live audio from a bus or hardware input and passes it through the mixer without recording it to disk Reverb return, delay return, submix, or monitor return
Master Fader Controls the level of its assigned output or bus path Main output level, cue output level, or bus master control
Folder Contains other tracks; a Routing Folder also passes and processes audio Organizing drums, dialogue, guitars, or other track groups
MIDI is instructions, not recorded sound
MIDI data can describe notes, timing, velocity, controllers, and other performance information. A MIDI track needs an instrument or external MIDI device to create audio. An Instrument track combines the MIDI side and an audio channel strip for a virtual instrument.

Track Format: Mono or Stereo

  • Create a mono audio track for one microphone, one guitar input, or another single-channel source.
  • Create a stereo audio track for a true two-channel source such as a stereo keyboard, stereo recorder, or stereo music file.
  • Create stereo Auxiliary Inputs for stereo reverbs, stereo delays, and stereo submixes.
  • Create a stereo Master Fader for a stereo main output path.
Do not create a stereo track for one microphone
One microphone produces one mono signal. Recording it to a stereo track can place the signal on only one side or duplicate it unnecessarily. A mono track can still be panned anywhere in a stereo mix.

Track Timebase: Samples or Ticks

Sample-based tracks keep clips anchored to absolute time. Tick-based tracks follow musical tempo and bar-and-beat changes. Audio tracks commonly begin sample-based. MIDI and Instrument tracks commonly begin tick-based because musical performances normally follow the session tempo map.

Create New Tracks

Build the practice track layout
  1. Choose Track > New or press Command+Shift+N on Mac. On Windows, press Control+Shift+N.
  2. In the first row, create four new mono Audio Tracks in Samples.
  3. Click the plus button to add another row.
  4. Create one new stereo Audio Track in Samples.
  5. Add one MIDI Track in Ticks.
  6. Add one stereo Auxiliary Input in Samples.
  7. Add one stereo Master Fader in Samples.
  8. Name the tracks by source or purpose, then click Create.

Each row defines a quantity, channel format, track type, timebase, and name.

Name before recording
Recorded audio files inherit the track name. Naming a track Lead Vocal before recording creates files that are easier to identify than files created from a default name such as Audio 1.
