Pro Tools: Interface and Navigation

Pro Tools separates timeline editing from mixer-style control. The Edit and Mix windows show the same tracks and the same session from two different working views.

Goals

  • Distinguish the Edit window from the Mix window.
  • Switch between the two main windows.
  • Show the track controls needed for basic routing.
  • Identify the four Edit modes and the primary Edit tools.

The Edit Window

The Edit window is organized around time. Use it to view waveforms and MIDI, place clips on the timeline, make selections, edit performances, and automate track parameters. Track controls can also display inserts, sends, and I/O beside the timeline.

The Edit window shows the timeline in the center and track controls along the left side.

The Mix Window

The Mix window is organized like a console. Each track appears as a vertical channel strip with inserts, sends, input and output selectors, pan, mute, solo, record controls, meters, and a fader. Use it when routing signals, balancing levels, panning, and adding processing.

The Mix window shows the same tracks as vertical channel strips.

One session, two views
Creating, deleting, naming, or routing a track in one window changes that same track in the other window. The windows do not contain separate copies of the session.

Switch Between Edit and Mix

Choose Window > Edit or Window > Mix. On a Mac, Command+Equals toggles between the Edit and Mix windows.

Show Track Controls in the Edit Window

Use the Edit Window View selector to show or hide track information. For this module, keep Inserts A-E, Sends A-E, I/O, Track Color, and Marker Controls visible. These controls make it possible to follow signal routing without leaving the Edit window.

Edit Modes

The Edit mode determines how clips and selections behave on the timeline.

  • Shuffle closes or creates space automatically when clips move.
  • Slip allows clips and selections to move freely to any time location.
  • Spot places clips at an exact entered time location.
  • Grid constrains clips and selections to the current grid value. Relative Grid keeps a clip's existing offset while moving it by grid increments.

Edit Tools

The main Edit tools include Zoomer, Trim, Selector, Grabber, Scrubber, and Pencil. Pro Tools can also display the Smart Tool, which combines Trim, Selector, and Grabber behavior according to the pointer's position over a clip.

Build a window-switching habit
Use the Edit window when time and clips are the focus. Use the Mix window when signal flow and channel controls are the focus. Switch often rather than forcing every task into one window.
