Pro Tools: Transport and Recording Controls

The Transport controls move through the session and control playback and recording. Recording requires two separate preparations: the destination track must be record-enabled, and the Transport must be armed for recording.

Goals

  • Identify the basic Transport buttons and counters.
  • Distinguish Track Record Enable from the Transport Record button.
  • Use input monitoring to hear a source before and during recording.
  • Prepare and complete a basic recording pass safely.

Open the Transport

Choose Window > Transport to open the floating Transport window. Basic Transport controls can also appear in the Edit window toolbar. The floating window can show counters, pre-roll, post-roll, selection values, MIDI controls, and expanded controls.

Source: Avid Pro Tools Reference Guide 2026.4, page 265.

Basic Transport Controls

  • Return to Zero moves to the beginning of the session.
  • Rewind and Fast Forward move the current location backward or forward.
  • Go to End moves to the end of the session.
  • Stop stops playback or recording.
  • Play starts playback from the timeline insertion point or selection.
  • Record arms the Transport. When Play starts, Pro Tools records on each record-enabled track.
The Spacebar controls Play and Stop
Press the Spacebar to start or stop playback. If the Transport Record button is already armed and at least one track is record-enabled, starting playback begins recording instead.

Track Record Enable and Transport Record

Track Record Enable chooses which track will receive new material. The Transport Record button prepares the Pro Tools recording system. These controls work together but do different jobs.

  • A track's Record Enable button flashes red when that track is armed.
  • The Transport Track Record Enable indicator turns red when at least one audio track is armed.
  • The Transport Record button flashes when Pro Tools is ready to record.
  • Recording begins only when playback starts after the Transport has been armed.

A record-enabled audio track shows a red Record Enable button and red fader. Source: Avid Pro Tools Reference Guide 2026.4, page 763.

Armed does not mean recording
A red or flashing record control means the system is prepared. Confirm that the Transport is moving and the track is writing a new clip before assuming the performance is being recorded.

Input Monitoring

The TrackInput Monitor button lets a track monitor its assigned input. In Auto Input Monitoring, a record-enabled track normally monitors the live input while stopped and during recording, then plays existing track material during playback. In Input Only Monitoring, the live input remains monitored instead of switching to recorded material.

Watch the meter before pressing Record
Record-enable the track and perform at the loudest expected level. Set input gain on the hardware interface while watching the track meter. The track fader changes monitoring level after the signal enters Pro Tools and does not set the recorded input level.

Complete a Basic Recording Pass

Recording checklist
  1. Create and name a mono Audio track for one microphone or one interface input.
  2. Assign the correct hardware input and the correct monitor output.
  3. Connect the source and set the interface preamp gain with the performer producing the loudest expected level.
  4. Click the track's Record Enable button.
  5. Confirm that the meter responds and that the source is audible through the intended monitoring path.
  6. Place the timeline insertion point where recording should begin.
  7. Click Record in the Transport. The button flashes.
  8. Click Play or press the Spacebar to begin recording.
  9. Press the Spacebar or click Stop to end the pass.
  10. Disarm the track, return to the beginning of the new clip, and listen to the recording.
Protect hearing and equipment
Keep monitor and headphone levels low while connecting sources, enabling phantom power, changing routing, or troubleshooting. Raise listening level only after the signal path is stable.
