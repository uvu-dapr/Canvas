Pro Tools: Introduction

Pro Tools is a digital audio workstation used to record, edit, route, mix, and deliver professional audio. This module introduces the parts of Pro Tools that must be understood before recording or mixing: the interface, the Playback Engine, I/O paths, track types, inserts, sends, and basic signal routing.

Goals

  • Explain what an audio interface does and connect it correctly to Pro Tools.
  • Select the correct Playback Engine and confirm input, output, and bus paths.
  • Connect headphones to a dedicated headphone output using the correct connector.
  • Identify the Edit and Mix windows and the basic tools used in each.
  • Create and explain audio, MIDI, Auxiliary Input, and Master Fader tracks.
  • Route signals with inputs, outputs, buses, inserts, and sends.

Module Sequence

  1. Learn the Edit and Mix windows, Edit modes, and Edit tools.
  2. Connect the audio interface, select it as the Playback Engine, and confirm I/O paths.
  3. Create the correct track types for audio, MIDI, routing, and output control.
  4. Use the Transport and distinguish track arming from Transport record readiness.
  5. Compare Auto Input Monitoring with the track Input Monitor button.
  6. Follow the signal through inputs, inserts, sends, buses, Auxiliary Inputs, and outputs.
  7. Complete the Pro Tools Introduction quiz.
Terminology
I/O means input and output. A path is a named route that a signal can use. A bus is an internal path inside Pro Tools. A hardware input or output connects Pro Tools to a physical connector on an audio interface.
