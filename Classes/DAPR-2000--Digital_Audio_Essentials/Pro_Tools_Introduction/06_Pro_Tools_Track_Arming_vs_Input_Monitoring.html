Pro Tools: Track Arming vs Input Monitoring

Track Arming and Input Monitoring look similar, but they control different things in Pro Tools. This page shows what you actually hear in each combination of transport state and track state.

Key:

Track Armed means the record enable button is on.

Input Monitoring means the input I button is on.

Pro Tools Track Monitoring Modes
Transport State Track State What You Hear Notes
Playhead Parked Track Armed You hear the live input on that track. When Pro Tools is parked, Track Armed and Input Monitoring behave the same. Both let you hear the input signal.
Input Monitoring On You hear the live input on that track.
Playing Track Armed with Input Monitoring off You hear what is recorded on the track at the playhead position. If the track has audio, it plays. If the track is empty, you hear silence. During playback, Track Armed follows the audio clips on the track rather than the input. Input Monitoring ignores what is on the track and monitors the input signal instead.
Input Monitoring On You hear only the live input. You do not hear the audio clips on the track.
Recording Track Armed and recording You hear the live input that is being recorded to the track. During recording, Track Armed and Input Monitoring behave the same. You hear the input signal while it is written to the track.
Input Monitoring On during recording You hear the same live input that is being recorded.

See It In Action

This session shows four tracks during playback, each in a different combination of Record Enable and Input Monitoring. Compare this to the Playing row of the table above.

Audio 1 - Armed, Input Monitoring off, no clip on the track. Silent during playback.

Audio 2 - Not armed, Input Monitoring on, no clip on the track. You hear the live input.

Audio 3 - Armed, Input Monitoring off, clip present. The recorded clip plays back.

Audio 4 - Not armed, Input Monitoring on, clip present. The clip is ignored. You hear the live input instead.

Tip: Audio 3 and Audio 4 both have a recorded clip, but only Audio 3 plays it back. Audio 4 is Input Monitoring, so it skips the clip entirely and monitors the live input instead.
