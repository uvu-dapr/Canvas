## How to use this

Every download lives at:

```
https://uvu-files.adamo.workers.dev/<Course_Folder>/<Module_Folder>/<Filename>
```

The module folder is the Canvas module name with three substitutions: space becomes `_`, colon becomes `__`, slash becomes `-`. Commas and apostrophes drop out and `&` becomes `and`.

**Copy the URL from the table. Do not construct it from memory and do not reuse a URL from an older brief.** Every path on this page changed on 2026-09-23.

Files under `_unplaced/` have no URL yet. No page in the current cartridge references them, so they have not been assigned to a module. Do not link to them.
